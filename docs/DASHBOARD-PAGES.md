# 🗺️ 後台頁面清單

後台指登入後左側欄工作台 `/dashboard/[role]/…`，三種角色：學生、老師、管理員。2026-09-08 依 Roy 要求一次做完一版（不再出多版本評選），視覺與互動參考 [demos.shadcndashboard.dev](https://demos.shadcndashboard.dev/)：字少、數字大、圖表只呈現真實業務量、每個動作有回饋。全部讀假資料，身分由路由參數決定（原型）。

## 1. 外框

- **側欄** 240px，可收合成 icon；品牌 logo、分組導覽（總覽／專題事務／分組與產學／評分與簽核／系統管理）、待辦徽章、右下角「回到前台網站」與使用者。
- **頂列**：側欄開關、頁名、搜尋（⌘K，原型未接）、通知鈴（下拉 Inbox，未讀有脈動小點）、帳號選單（個人資料、回前台、切換角色、登出）。**沒有深淺主題切換**，固定白底。
- **回饋**：換頁進度條、內容進場、卡片進場錯落、圖表長出動畫、卡片 hover 上浮、按鈕按下回彈；全部尊重 reduced-motion。
- **內容區** 淡灰底，白卡浮出；手機一欄，側欄改抽屜。

## 2. 路由與角色

| 路由 | 學生 | 老師 | 管理員 |
|---|---|---|---|
| `/` 首頁 | 問候＋下一個截止倒數環、四統計磚、待完成、我的組別、待我同意、已繳交、近期公告 | 問候＋已送出評分環、四統計磚、評分佇列、可認領產學組、待我同意、指導組別繳交狀態 | 問候＋已分組環、四統計磚、需要處理、近 7 天正式繳交長條圖、收件完成率、老師評分進度、儲存與備份、最近高權限操作 |
| `/inbox` 通知 | 截止／繳交／簽核／系統 | 評分／簽核／繳交／系統 | 帳號／逾期／缺評／備份 |
| `/affairs` 專題事務 | 待完成／已逾期／已繳交卡片 | 指導組別 × 收件項目矩陣 | 工作台：發布位置篩選、發布中／收件／逾期統計、項目列表（進度、狀態、編輯）、各位置收件概況 |
| `/affairs/[id]` | 組別共用表單（儲存草稿、正式送出回執、歷次版本；截止鎖定） | 該項目我的各組狀態與版本 | 各組狀態、收件進度環、欄位摘要、逾期組別「重新開放」（必填理由與新期限、影響預覽） |
| `/editor/[id]`、`/editor/new` | — | — | 編輯器簡化版：上方標題／主要發布位置（單選）／對象／截止／摘要；左側 16 種區塊（內容、填寫、選擇、日期與檔案）；中間欄位清單（選取、上下移、複製、刪除）；右側欄位設定；預覽（桌機／手機、學生視角）；發布回執；已有回覆時改結構標示建立新版本 |
| `/groups` | 我的組別（確認進度環、成員狀態、組長）、找組員（僅 opt-in 者，電話不公開） | 分組總覽統計、可認領產學組卡片（first-success，含衝突訊息）、全部組別 Data Table | 分組總覽統計、全部組別 Data Table（指派／重派需理由） |
| `/industry` | 公開合作案卡片（連前台詳情） | 我的合作案：新增／編輯（長文字 textarea、聯絡資料標私有、公開／草稿）、下架 | 全部合作案、負責老師、連結組別 |
| `/grading` | 明確頁面：v1 學生看不到成績 | 評分工作台：左組別清單（未開始／已暫存／已送出）、右評分表（數字或 A–F）、即時階段成績、暫存、正式送出回執並鎖定 | 成績管理：方案版本與權重合法性、老師進度、各組結果、更正（保留原值＋理由） |
| `/grading/[groupId]` | — | 直接開該組評分表 | — |
| `/signoff` | 同意書全文、閱讀並同意（確認）／不同意（必填原因）、五人進度環 | 待我同意（五人全同意後）、指導組別進度分段條 | 各組進度分段條、缺誰、重置（必填原因，不可代簽） |
| `/accounts` | — | — | 待審核／已核准／已停用統計、Data Table（搜尋、角色／屆別／狀態篩選、排序、勾選匯出 CSV、批次停用預覽）、審核對話框、匯入名單 CSV 三步預覽 |
| `/files` | — | — | 儲存用量環、依類型比例、公開資源／公告附件／組別繳交篩選、被引用不可刪 |
| `/audit` | — | — | 事件時間線、依角色篩選、理由顯示 |

## 3. 元件

`src/components/dashboard/`：`primitives.tsx`（Panel、StatTile、Greeting、ActionRow、Pill、ProgressBar、EmptyState、PageTitle）、`charts.tsx`（Sparkline、MiniBars、Ring、SegmentBar、BarChart、HBar，純 SVG）、`group-form.tsx`、`item-editor.tsx`、`grading-workbench.tsx`、`signoff-actions.tsx`、`group-actions.tsx`、`industry-form.tsx`、`reopen-dialog.tsx`、`override-dialog.tsx`。`src/components/layout/`：`app-sidebar.tsx`、`dashboard-header.tsx`。

## 4. 原型未接的東西

搜尋（⌘K）、通知標為已讀、多角色切換正式版（只在帳號持有多角色時出現）、老師首次登入補資料、臨時密碼強制改密碼、永久刪除帳號的二次確認頁。全部等 Better Auth 與 Drizzle 接上後做（規格 §16.7 第一條垂直切片）。
