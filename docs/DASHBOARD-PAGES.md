# 🗺️ 後台頁面清單

後台指登入後左側欄工作台 `/dashboard/[role]/…`，三種角色：學生、老師、管理員。2026-09-08 第一版 Roy 覺得「資訊量太大、單調、logo 擠」，改出 Claude Design 畫布評選（[畫布](https://claude.ai/code/artifact/06a0e5a8-03be-43ad-a2cf-70a69491da77)：四個方向 → D 內容區＋C 側欄 → 每角色五個版本），Roy 定案 **V1 模組網格**，不放插畫（怕有人介意 AI 生成圖）。全部讀假資料，身分由路由參數決定（原型）。

## 0. 2026-09-09 第二輪：V4 定案為底，首頁改成「本屆時程」

Roy 看完 V1–V4 選 **V4 系網深藍**，並提出下列修改；V1–V3 已刪除，只剩 V4 底＋首頁時程三種做法（右下角切換，cookie `fju-dash-variant`＝`rail`／`agenda`／`chart`）：

| 做法 | 一句話 |
|---|---|
| A 軌道 | 橫向路線圖，一站一階段；現在這站放大，下面列這階段要做的事 |
| B 行程 | 直式行程表，左邊日期、右邊階段；現在的階段展開 |
| C 甘特 | 每階段一條橫槓對到月份、今天一條線；下面列這階段要做的事 |

Roy 這輪的話與對應改法：

- 「側欄顏色、上面那個跑條、首頁旁邊有一根線很怪」→ 選中改成白色 13% 圓角塊＋橘 icon，**不畫左線**；側欄右緣的 rail 線拿掉；頂列的分隔線拿掉；換頁進度條改 2px 貼在最上緣、不發光。
- 「收合的時候圖片歪歪的」→ 展開用橫式 logo 反白（固定高度框、object-contain）；收合只露 logo 最左邊的圖形（同一張圖 object-cover 靠左裁）；收合寬 60px。
- 「變色會突然跳白色，想要奢華沒奢華起來」→ 窗簾改成 View Transitions 從月亮鈕位置一圈擴開；不支援或 reduced-motion 直接切。
- 「里程碑太怪，應該獨立一頁、左邊時間軸」→ 新增 `/timeline`「本屆時程」：左邊直式階段列表、右邊該階段說明、我要做的事、其他角色在做什麼。八個階段（帳號啟用、分組、指導老師、題目與計畫書、第二次文件繳交、系統驗收、專題發表、成品繳交與同意書）來自規則 §7／§8 與 0715 會議，資料在 `fixtures.ts` 的 `SCHEDULE`。
- 「首頁上面那欄沒問題；公告放時間軸下面；其他東西有才跳出來；現在要做不實用」→ 首頁＝問候 → 統計一條 → 本屆時程（現在這階段要做的事列在裡面）→ 公告 → 有才出現的模組（學生：已逾期／我的組別／同意書；老師：待評分／可認領／待我同意／指導組別／合作案；管理員：需要處理／分組／收件／評分進度／近 7 天／儲存／最近操作）。
- 「搜尋要一點開就跳出來那種」→ ⌘K 面板（cmdk＋shadcn command）：背景霧化、大字輸入、分群搜頁面／組別／學生／項目／合作案。
- 「我的專題事務像作業區」→ 學生導覽改叫**作業區**：每件作業一列，左邊截止日大字、狀態、誰在什麼時候送出第幾版；上方待繳／已繳交／已逾期篩選。（術語：CONTEXT.md 的「專題事務」不變，作業區是學生端的稱呼。）
- 「我的組別有點醜」→ 改成五個座位的名單：頭像圈、組長標、已確認打勾、空位虛線。
- 「同意書能不能直接看 PDF 原檔」→ 系辦在簽核頁上傳 PDF（換版會重置所有人的同意）；學生頁內嵌 PDF 原檔，勾「已完整閱讀」才出現同意／不同意。示範檔 `public/docs/consent-2026.1.pdf`。

定案後要刪：`dash-variant*`、`variant-switcher.tsx`、`/api/proto-variant`、`home-variants.tsx` 裡沒選中的兩種時程；第 1 節改寫成定案版規則。

## 1. 外框與首頁規則（V1 模組網格）

- **側欄** 240px，淺底，底部「收合選單」鈕可收成 icon；橫式 logo 原尺寸、下一行只寫「專題管理平台」；分組導覽（首頁、通知／專題事務、內容編輯器、檔案管理／分組總覽、產學合作／評分、成績管理、同意書、簽核／帳號管理、操作紀錄）；**選中＝暖白底＋橘色左線＋橘 icon**；徽章橘色。使用者與「回到前台」只在頂列帳號選單，側欄不重複。
- **頂列**：側欄開關、頁名、搜尋（⌘K，原型未接）、通知鈴（下拉 Inbox）、帳號選單（個人資料、回前台、切換角色、登出）。沒有深淺主題切換。
- **色調（Roy 2026-09-08 第三輪）**：只有一個主軸色＝系網橘。橘＝主要動作、目前選取、最新達成、統計磚的重點 icon 方塊；綠＝完成、紅＝逾期；其餘全部中性灰。通知、圖表、徽章都照這條。
- **深淺色**：後台可切黑白（頂列月亮／太陽鈕），切換是一塊布從上往下蓋住、換色、再往下滑走；只影響後台，前台固定白。
- **內容區** `#f4f6f9`；卡片＝白底、14px 圓角、柔陰影，不用邊框、不做卡中卡；數字一律黑；不做進場動畫（換頁淡入除外）。
- **首頁固定三層**：問候＋一句話（不放按鈕，動作在清單裡）→ 四張統計磚 → 三欄模組網格。
- **里程碑模組永遠在**：本學期／本屆里程碑一條路，做完一格亮一格，最新達成橘色微光（Steam 成就感）；其他模組收起後，完成的東西在這裡看得到。
- **模組規則**：只有「現在要做」固定存在（占兩欄）；其他模組**有才出現**（學生：組員確認未滿五人、同意書等我同意、已繳交有東西；老師：可認領產學組、待我同意、指導組別、我的合作案；管理員：分組、近 7 天、老師評分進度未完成、收件、儲存、最近操作），完成後自動收起、其他磚補位；全部沒事時「現在要做」變成一句話占位，不放插畫。
- **回饋**：換頁進度條、卡片 hover 微浮、按鈕按下回彈；尊重 reduced-motion。手機一欄、側欄改抽屜。
