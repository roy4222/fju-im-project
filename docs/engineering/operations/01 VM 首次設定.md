## 步驟與預期

1. `sudo apt update && sudo apt install -y docker.io docker-compose-plugin ufw`；預期 `docker --version` 有輸出。
2. `sudo usermod -aG docker $USER` 後重新登入；預期 `docker ps` 不需 sudo。
3. 建目錄 `sudo mkdir -p /srv/fju/{files,tmp,backups,postgres} && sudo chown -R 1000:1000 /srv/fju`。
4. `sudo ufw allow 22,80,443/tcp && sudo ufw enable`；預期只開三個 port。
5. 建 `/srv/fju/app/.env`（600 權限）依 SOP 02 清單填值；`docker login ghcr.io`（只讀 PAT `read:packages`，只存在 VM 的 docker 設定；不放 GitHub Secrets）。
6. 放 `docker-compose.yml`、`Caddyfile`、`deploy.sh`（來自 repo `ops/`）；`chmod +x deploy.sh`。
7. `docker compose up -d postgres caddy`；預期 Caddy 取得憑證（`docker compose logs caddy` 顯示 certificate obtained）。
8. 記錄 `df -h`、`free -m`、`nproc` 到證據；更新 📍 目前進度的 VM 列與查證日期。
