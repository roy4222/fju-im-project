## 步驟與預期

1. `.github/workflows/health-cron.yml` 每 5 分鐘 `curl` `/api/health`；非 200 或 `worker.lastTickAt` 過舊連續 3 次 → workflow 失敗 → GitHub Actions 失敗通知信寄 Roy（Roy 在 GitHub 通知設定開啟；零額外服務）；另可選 `ALERT_WEBHOOK_URL`（Discord 等，Roy 決定）。v2.1（2026-09-12）：通道具體化；現況見 [00 Roy 前置工作清單](<00 Roy 前置工作清單.md>) §4.4。
2. worker 每小時量測 `df` 寫 `storage_stats`（契約 01 §5；E-06，取代原「VM cron」寫法）；≥80% → 站內通知管理員＋`ALERT_WEBHOOK_URL`（未設則只站內；通知的 kind 與型別待 D-04）。
3. Caddy 存取日誌：每日統計 5xx 比率（腳本），>1% 通知。
4. 備份失敗告警由 SOP 04 產生。
5. 告警通道與產品 Email 分開；產品 Email 延後。
