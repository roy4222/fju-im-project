## 9. 判定

## 10. 失敗後
步驟 1–5 失敗：刪除屆別不可（無刪除功能）→用另一個 code `115-TEST-2` 重做並在 manifest 註記；步驟 6–7 失敗：可重新匯入（新版本）；步驟 8–10 失敗：不重複建立同 Email，改用「重新核發臨時密碼」。修正後同版本可局部重跑本劇本；換版本則整條主線重新開始（新 runId）。
