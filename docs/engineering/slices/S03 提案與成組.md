# S03｜找組員、提案、確認、終止、例外組、組長

## 成果
學生開關「公開找組員」；組長發起五人提案、五人各自確認、最後一人確認即成立；拒絕／撤回／到期／管理員作廢一律終止並釋放；管理員建三人例外組（核可依據、指定組長；測試環境用標示的模擬核可資料）；組長更換與接任；通知：邀請、終止、成立、組長更換。

## 模組與前置
03、08；前置 S02。

## 進場資料與產生方式
S01 核准的 13 位學生；A1 從 UI 操作。

## schema／API／狀態依賴
契約 01 §3「03」提案／組別／membership／leader 表；`GroupCommand`（propose…changeLeader、createExceptionGroup、voidProposal）、`GroupMembershipQuery`；`due_work(proposal_expiry)` handler；事件 proposal.*、group.established、group.leader_changed。

## 責任範圍、公開介面、跨模組協議
成立單一交易與唯一約束；到期＝min(設定天數, 成組截止)，成組截止來自 S02 階段；`groups.exception_basis.simulated` 只在 staging 允許。頁面：`/dashboard/student/group`（提案、確認、拒絕、撤回、到期時間、終止紀錄）、`/dashboard/admin/groups`（例外組表單、組長更換、作廢）。

## 正常與拒絕路徑；重試／回滾／恢復
拒絕：`ALREADY_MEMBER`、`INVITED_ELSEWHERE`、`PROPOSAL_NOT_OPEN`、零人／無核可依據 `VALIDATION_FAILED`。競態：兩提案同時成立含同一人 → 一者回滾終止。重試：確認同 requestId 回原回執。
