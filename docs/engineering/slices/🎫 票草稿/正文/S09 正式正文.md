# S09 正式正文｜成員異動、組長更換、解散、重派連動與解散閱覽

> 本檔是 S09 每張票的「可讀正文層」，票號、順序與 BLOCKED 標記照票草稿；技術九欄由產生器自動附在折疊區，這裡不重貼。環境依切片卡為 staging（未就緒時可用 local 並標明）。測試帳號只寫角色代號：A1 管理員；S01–S05 第一組 G1 成員（S01 組長）；SX6 尚未加入任何組的已核准學生；S06、S07 第二組 G2 成員；S11、S12 第三組 G3 成員，S13 是 G3 解散前已被移出的人，S15 是已停用的學生；T1、T2、T3 老師（T1 原是 G1 主指導；G3 解散前主指導由 T2 重派給 T3）。本切片不新增資料表，全部建立在 S06（指導）、S10（評分）、S11（簽核）已交付的功能之上。

### S09-01 [模組03 分組、指導與產學] 管理員換組員：先看影響預覽，再執行、接任組長並通知全組
- **票型**：feature
- **這張做什麼**：組別成立後有人要退出或補人，管理員 A1 在組別管理頁對 G1 按「換成員」，選要移出的人（S05）、要加入的人（SX6）、填理由，先看到一張影響預覽（異動前後的成員、目前簽核版本會失效、SX6 會拿到什麼、S05 會失去什麼），確認後才真正執行。執行後 S05 立刻打不開 G1 的內容（但署名與已交的東西保留），SX6 可以看共用草稿與歷史版本，G1 目前的簽核版本（包括已完成版本）自動失效等系辦重建，異動前後所有成員與主指導各收一則通知，S05 只收到「你已被移出」的本人說明。若移出的是組長必須先指定接任，若移出後組裡沒人則拒絕並提示改走解散。
- **做到哪裡**：本票交付影響預覽（含預覽有效期，過期要重做）、執行、接任組長、歷史版本仍顯示當時成員、成員異動通知（含新成員對進行中組別收件的「新收件」補通知）、被移出者失權。只有管理員可換組長，該功能由 S03-09；主指導重派由 S09-02；解散由 S09-03；組別收件的收件對象是「組」，不因換人改名單（個人收件的停用／跨屆規則由 S08）。本票目前是「可操作功能」。
- **Roy 如何確認**：staging（或 local）；用 A1、S05、SX6；要先有已成立的 G1（S01–S05、主指導 T1）、G1 有一個收集中的簽核版本、一個尚未截止的組別收件、SX6 已核准且不在任何組；從管理員後台 → 分組 → G1 → 換成員。

  | 操作 | 預期看到 |
  |---|---|
  | A1 選移出 S05、加入 SX6，理由留空按預覽 | 被拒，提示理由必填 |
  | 填理由後按預覽 | 影響預覽列出：異動前後成員、G1 目前簽核版本將失效、SX6 將取得共用草稿與歷史、S05 將失去存取；此時什麼都還沒改 |
  | 等預覽過期（工程可縮短時限）再按執行 | 被拒，提示「預覽已過期，請重做」；名單不變 |
  | 重做預覽後執行 | 回執含異動摘要與「簽核目前版本已失效，請建立新版」；G1 名單變成 S01–S04＋SX6 |
  | 改試移出組長 S01 但不指定接任 | 被拒；指定 S02 接任後才成功，組長標示變 S02 |
  | 對只剩一人的組把最後一人移出 | 被拒，提示「請改走解散」 |
  | 換 S05 登入 | 通知匣只有一則本人異動說明（沒有組別入口）；直接開 G1 共用草稿網址顯示「無法存取」 |
  | 換 SX6 登入，再換 S01 登入 | SX6 通知匣有加入通知與每個進行中組別收件的「新收件」；S01 通知匣有成員異動通知；兩人打開 G1 歷史版本仍顯示當時（含 S05）的成員；重新登入後名單不變 |
- **誰確認**：工程核對／Roy 畫面操作確認。
- **原型畫面**：

  ![管理員｜組別詳情抽屜｜成員確認狀態、指導老師、各項繳交](<../../../../product/assets/prototype-2026-09-11/admin--groups-detail.png>)
  原型 2026-09-11；正式版差異：新增「換成員」入口與影響預覽對話框（理由、接任組長、預覽過期提示），執行後簽核目前版本失效且不自動建版。

### S09-02 [模組03 分組、指導與產學] 管理員重派主指導時，逐筆決定評分指派怎麼處理，簽核只失效不自動建版
- **票型**：feature
- **這張做什麼**：A1 把 G1 的主指導從 T1 換成 T2。重派對話框會列出 T1 在 G1 的評分指派（期中、期末），預設都不勾：不勾就執行，評分完全不動（T1 仍是評分老師、T2 不會自動取得評分權），只有簽核目前版本失效、等系辦建新版，全組與 T2 收到指派通知、T1 收到原老師通知。勾了某一筆，就要對那一筆選「保留給 T1／替換給 T2／新增 T2 一份」，執行時逐筆套用。若 A1 開著預覽期間 T1 剛好送出正式分，執行會被擋下並整體回滾（指導、簽核、評分都不變），要重新預覽。舊簽核頁上學生按同意會看到「此版本已失效（主指導變更），等待管理員建立新版」。
- **做到哪裡**：本票交付重派對話框的評分指派勾選與三選一、逐筆採計、預覽衝突整體回滾、簽核只失效不建版的瀏覽器走法。三選一本體與預覽計算由 S10-09；簽核失效本體由 S11-08；管理員建新版由 S11-04；重派對話框的基本結構由 S06-06。本票目前是「可操作功能」。
- **Roy 如何確認**：staging（或 local）；用 A1、T1、T2、S03；要先有 G1（主指導 T1）、T1 在 G1 有期中評分指派、G1 有一個收集中的簽核版本且 S03 尚未同意；從管理員後台 → 分組 → G1 → 重派。

  | 操作 | 預期看到 |
  |---|---|
  | A1 開重派對話框選 T2 | 對話框列出 T1 在 G1 的期中評分指派，預設不勾 |
  | 不勾直接執行 | 回執「評分指派未變動；簽核目前版本已失效，請建立新版」；G1 主指導顯示 T2 |
  | 換 T1 登入 → 評分工作台 | 仍看得到 G1 的指派、仍能暫存；換 T2 登入，評分工作台沒有 G1 |
  | 換 S03 登入，在原本開著的簽核頁按同意 | 被拒，顯示「此版本已失效（主指導變更），等待管理員建立新版」，沒有新版入口 |
  | A1 建立新版後，S03 重載簽核頁 | 出現新版入口；T1 開該組簽核顯示「無法存取」，T2 看得到 |
  | 換一組重做：A1 開對話框勾選期中指派並選「替換給新老師」，先不執行；另開 T1 送出該筆正式分；回到 A1 執行 | 被拒，提示「評分狀態已變更，請重新預覽」；主指導、簽核、評分三者都沒變 |
  | A1 重新預覽並執行 | 回執逐筆結果；離開再回來，主指導與評分指派的狀態一致 |
- **誰確認**：工程核對／Roy 畫面操作確認。
- **原型畫面**：
  ![管理員｜重派｜評分與簽核指派一併移轉，理由必填](<../../../../product/assets/prototype-2026-09-11/admin--groups-reassign-dialog.png>)
  原型 2026-09-11；正式版差異：對話框列出評分指派供逐筆勾選三選一（預設不勾、不勾則評分不動），簽核只失效不自動移轉，預覽期間有新正式分則整體回滾。

### S09-03 [模組03 分組、指導與產學] [BLOCKED D-03] 管理員解散一組：預覽、填理由、執行，同時凍結繳交、停止評分、作廢簽核並通知相關人
- **票型**：decision
- **這張做什麼**：A1 對 G2 按「解散」，先看預覽（解散前的成員、主指導、會被停止評分工作的老師、會被作廢的簽核版本、還沒完成的收件），填理由、二次確認後執行。執行後 G2 標「已解散」：組員任何草稿儲存、送出都被擋；評分草稿失效、已正式送出的分數保留唯讀、老師的評分指派結束；簽核目前版本作廢；成員與主指導關係結束，組員回到未分組狀態、之後可以另組新組；解散前的成員、主指導與被停止評分的老師各收一則解散通知。
- **做到哪裡**：本票交付解散預覽、確認對話框、執行（一次做完繳交凍結、評分停止、簽核作廢、關係結束、通知）、任一步失敗整體回滾。解散後誰能看什麼由 S09-04；評分停止與簽核作廢的本體由 S10-13、S11-08；新組的名單加入與指定重開由 S08。本票目前是「決策草案」：D-03 未決前，「已完成的最終文件簽核版本要不要一併作廢」這一段不施工。
- **Roy 如何確認**：等 D-03 決定；決定後補確認步驟。這個決定影響的是：一組解散時，它已經簽完的「最終文件授權」要不要跟著失效——若失效，這組已公開的精選會被閘門下架；若不失效，精選維持公開。其餘部分（凍結、停止、作廢進行中版本、關係結束、通知）已定，決定後一併補 Roy 的操作表。
- **誰確認**：Roy 畫面操作確認（決定後）／工程核對。
- **原型畫面**：
  ![管理員｜/dashboard/admin/groups｜解散預覽已存在；規則仍須依Q-ID討論](<../../../../product/assets/prototype-2026-09-11-supplement/admin--group-dissolve--preview.png>)
  原型 2026-09-11；正式版差異：預覽改列成員、主指導、將停止的評分老師、將作廢的簽核版本與未完成收件，理由必填並二次確認，執行同時凍結繳交、停止評分、作廢簽核。

### S09-04 [模組03 分組、指導與產學] 解散後誰還能看什麼：依解散當下的身分轉唯讀，管理員可查可匯出
- **票型**：feature
- **這張做什麼**：一組解散後，不是全部人都失去或恢復存取，而是照「解散那一刻誰是有效成員、誰是主指導、誰有評分指派」定唯讀範圍。G3 的成員 S11 還能看自己組的正式版本與附件（看不到成績）；解散前才接手的主指導 T3 能看組別正式版本與自己的評分，看不到別的老師的分數與個人問卷；解散前就被移出的 S13、被換掉的 T2 不會因為解散而恢復存取；沒被指派的 T1、已停用的 S15 被拒；A1 全部可查並可匯出。頁面標示「此組已解散（唯讀）」與解散時間，理由只有管理員看得到；附件下載與頁面的允許／拒絕完全一致。
- **做到哪裡**：本票交付解散快照查詢、六種角色的唯讀規則、學生「我的繳交」頁與組別歷史頁的已解散橫幅（隱藏所有寫入按鈕）、老師組別頁的「評分已停止」顯示、管理員組別詳情的解散資訊與匯出、附件下載同規則。封存的唯讀與遮罩由 S13、S12-10；解散本體由 S09-03；成績更正拒抵認由 S10-07。本票目前是「可操作功能」。
- **Roy 如何確認**：staging（或 local）；用 S11、S13、T3、T2、T1、S15、A1 七個帳號；要先有依劇本 B02 走到解散的 G3（解散前已移出 S13、主指導由 T2 重派給 T3、有正式版本與附件、T3 與另一位老師各有已送出的評分）；學生從後台 → 我的繳交，老師從後台 → 指導組別，管理員從後台 → 分組 → G3。

  | 操作 | 預期看到 |
  |---|---|
  | S11 登入 → 我的繳交 → G3 | 頁面頂端「此組已解散（唯讀）」與解散時間，沒有理由、沒有任何送出或編輯按鈕；能開正式版本、能下載附件；整頁找不到分數 |
  | S11 直接開 G3 的成績網址或請求 | 顯示「無法存取」 |
  | S13 登入，開 G3 任何頁面或附件下載 | 一律「無法存取」 |
  | T3 登入 → 指導組別 → G3 | 標「已解散（唯讀）」「評分已停止」；能看組別正式版本與自己那份評分；看不到另一位老師的分數、看不到個人問卷 |
  | T2、T1 各自登入開 G3 | 都是「無法存取」，附件下載同樣被拒 |
  | S15 嘗試登入 | 已停用，無法登入 |
  | A1 登入 → 分組 → G3 | 看到解散時間與理由，可開全部版本並匯出 |
  | S11 重新登入再開 G3 | 仍是唯讀狀態，沒有任何寫入入口 |
- **誰確認**：工程核對／Roy 畫面操作確認。
- **原型畫面**：無原型畫面（待實作畫面）。
