### S12-02 [模組09 公開展示與共用介面] 管理員登記海報來源並做人工核閱，換檔就要重核
- **票型**：feature

- **Roy 如何確認**：staging（或 local）；用 A1 登入；要先有 S11 建好的 G1 精選草稿，草稿已附一張標示「模擬」的海報；從管理員後台 → 精選（`/dashboard/admin/showcase`）→ 打開 G1 草稿。

### S12-03 [模組09 公開展示與共用介面] 做出「能不能公開」的判定：先查個資、再查授權涵蓋、最後查素材核閱
- **票型**：foundation
- **這張做什麼**：工程做一個純判定服務，回答「這一版精選現在能不能公開」。順序固定三關：第一關文字個資檢查（題目、摘要裡有沒有手機號、Email）；第二關授權有效且逐項涵蓋（當屆看簽核授權版本，歷屆看外部授權；用途、題目、摘要、每張素材的檔案版本、影片連結都要在授權範圍內）；第三關每張素材的這一版檔案都有人工核閱通過。哪一關先擋就回哪一個原因，只回一個。發布（S12-04）與每次公開頁請求（S12-05）都共用這一個判定，所以授權一失效，公開頁立刻擋住，不用等背景工作。
- **做到哪裡**：本票交付判定服務、電話與 Email 兩種正則、對「草稿內容」與「已發布版本」兩種輸入的支援，以及完整的單元與整合測試（四種拒絕、兩種授權來源各一通過、順序驗證）。發布交易由 S12-04；公開端點由 S12-05；外部授權的寫入由 S12-07（本票只讀）。本票目前是「工程基礎」，沒有畫面。
- **Roy 如何確認**：本票由工程驗證；Roy 在 E12 整體展示確認測試報告裡「閘門四拒」「兩種授權來源通過」「檢查順序 PII→涵蓋→核閱」三組測試都是綠燈；Roy 會在 S12-04 的發布畫面實際看到這三種拒絕文案。
- **誰確認**：工程核對。
- **原型畫面**：無原型畫面（待實作畫面）。

### S12-04 [模組09 公開展示與共用介面] 管理員按發布把草稿凍結成不可改的公開版本，可撤稿與重新發布，並看到閘門逐項結果
- **票型**：feature
- **這張做什麼**：A1 在精選草稿頁看到閘門結果區：授權是否有效、題目／摘要／海報版本／影片連結／用途逐項打勾、個資檢查結果、素材核閱狀態。按「發布」時系統跑 S12-03 的三關檢查，通過就把草稿當下的內容「拍成」一個不可修改的版本並公開；沒過就顯示對應的拒絕畫面（個資、授權未涵蓋、素材未核閱三種），草稿保留可以改。發布後再改草稿、再發布會產生新版本，舊版本留著不動。「撤稿」讓公開頁消失但版本保留；「重新發布」會再跑一次檢查。
- **做到哪裡**：本票交付發布、撤稿、重新發布三個動作、版本表寫入、素材引用轉到版本、公開快取失效、閘門結果區與三種拒絕畫面、稽核紀錄。草稿編輯由 S11；訪客端公開頁由 S12-05；授權失效自動撤稿由 S12-06。本票目前是「可操作功能」。
- **Roy 如何確認**：staging（或 local）；用 A1 登入；要先有 G1 精選草稿，且 G1 最終文件授權 v1 已簽核完成（劇本 P08 步驟 11）、海報已由 S12-02 登記但尚未核閱；從管理員後台 → 精選 → G1 草稿。

  | 操作 | 預期看到 |
  |---|---|
  | A1 打開 G1 草稿 | 閘門結果區顯示「授權有效且逐項涵蓋」、五項逐項打勾；海報「待核閱」 |
  | 海報未核閱就按「發布」 | 拒絕畫面「素材未核閱」（ASSET_NOT_APPROVED）；草稿仍在 |
  | 核閱海報通過，再把摘要加一段手機號碼並儲存，按「發布」 | 拒絕畫面「內容含個資」（PII_DETECTED），且先於授權檢查 |
  | 把摘要改回原文儲存，按「發布」 | 回執含版本號 v1；狀態變「已發布」 |
  | 再改一個字儲存後再按「發布」 | 回執版本號 v2；版本清單有 v1、v2 兩列，v1 內容不變 |
  | 按「撤稿」 | 狀態變「已撤稿」；版本清單仍在；再按「重新發布」回到已發布 |
  | 離開頁面再回來 | 狀態與版本清單不變 |
  | 換 S06 登入，直接開發布動作的網址 | 被拒（FORBIDDEN） |
- **誰確認**：工程核對／Roy 畫面操作確認。
- **原型畫面**：無原型畫面（待實作畫面；閘門結果與三種拒絕畫面列於模組 09 §7.2 缺口）。

### S12-06 [模組09 公開展示與共用介面] 授權一失效公開頁立刻擋住，背景工作隨後自動撤稿
- **票型**：feature

### S12-07 [模組09 公開展示與共用介面] 管理員補登歷屆作品的外部授權，登入者看歷屆一覽，訪客看榮譽榜
- **票型**：feature
- **這張做什麼**：以前沒有在系統上簽過授權的歷屆作品，A1 用「補登外部授權」填來源、可用範圍、核可人、日期、證據檔與涵蓋項目，之後這件作品就能走同一套發布流程公開；授權內容登記後不能改，要改就補登新一筆並讓舊的作廢。登入的學生、老師、管理員可以在「歷屆專題」看歷屆一覽，訪客會被導去登入。A1 也能建立、發布、下架榮譽榜項目，訪客在「榮譽榜」看到已發布的（封面圖一樣要先核閱）。

  | 操作 | 預期看到 |
  |---|---|
