# S06 正式正文｜主指導：認領、指派、重派、CSV 批次；合作案與連結

> 本檔是 S06 每張票的「可讀正文層」，票號、順序與 BLOCKED 標記照票草稿；技術九欄由產生器自動附在折疊區，這裡不重貼。環境依切片卡為 staging（未就緒時可用 local 並標明）。測試帳號只寫角色代號：A1 管理員、T1／T2／T3 老師、S01–S05 第一組 G1（一般組）成員、S06（G2 組長）／S07 第二組 G2（產學組）成員、G3（產學組，已指派 T2）、訪客（未登入）。合作案：C1（T2 建立並發布）、C2（T3 的草稿）。E03 出場的 G1／G2／G3 為進場資料。評分（S10）與簽核（S11）尚未存在，重派對話框的評分清單為空並註明。

### S06-01 [模組03 分組、指導與產學] 建立主指導指派、合作案與合作案連結三張資料表
- **票型**：foundation
- **這張做什麼**：工程在 S03 的組別表之上，再加三張表：「主指導指派」（誰在什麼時候是哪一組的主指導，含結束時間與理由）、「合作案」（老師建立的產學合作案，含只有案主與系辦看得到的私有欄位）、「合作案連結」（哪一組連到哪一案）。這三張表是認領、指派、重派、批次與產學連結全部功能的地基；資料庫規則直接保證同一組同時只有一位有效主指導、只有一個有效合作案連結。
- **做到哪裡**：本票交付一支建表腳本、兩條唯一規則、資料庫角色權限與對應的角色測試；空資料庫從頭逐切片升級要成功。任何畫面與操作都不在本票（頁殼由 S06-02 起）。本票目前是「工程基礎」。
- **Roy 如何確認**：本票由工程驗證；Roy 在 E06 整體展示確認 CI 的「空庫升級」與「舊資料升版」兩條工作都是綠燈，並看到工程附的三張表結構輸出與「同一組第二位有效主指導被擋下」的反例輸出。Roy 不需要讀 SQL。
- **誰確認**：工程核對。
- **原型畫面**：無原型畫面（待實作畫面）。

### S06-05 [模組03 分組、指導與產學] 管理員逐組指派主指導，或解除現有的指派
- **票型**：feature
- **這張做什麼**：一般組依抽籤結果由系辦指派：A1 在組別頁對 G1 按「指派」、選 T1、填理由，成功後 G1 全員與 T1 收到通知，學生首頁顯示同一位老師。要解除時按「解除」填理由，關係結束並通知。老師自己不能改指派；兩個管理員同時操作同一組，後者會被要求重新載入。
- **做到哪裡**：本票交付指派與解除兩個用例、指派對話框、解除確認、通知、操作紀錄。重派由 S06-06；批次由 S06-07。「解除指派」要通知誰，產品通知矩陣沒有這一列，票草稿暫依「該組全員與原老師」，待 Roy 定。本票目前是「可操作功能」。
- **Roy 如何確認**：staging（或 local）；用 A1、T1、T3、S01；要先有尚未指派的一般組 G1；從管理員後台 → 組別 → G1 列。

  |---|---|
  | A1 對 G1 按「指派」，選 T1，理由留空按確定 | 被拒，提示理由必填；G1 仍無主指導 |
  | 填理由後確定 | 回執成功；G1 列顯示主指導 T1 |
  | 換 S01 登入 | 首頁顯示指導老師 T1；通知匣有一則指派通知 |

### S06-07 [模組03 分組、指導與產學] 管理員用 CSV 一次指派多組，先看六類預覽再逐列執行
- **票型**：feature
- **這張做什麼**：抽籤結果一次有幾十組要指派，A1 選好屆別、上傳兩欄的 CSV（組別代碼、老師登入 Email）。系統先給預覽，把每一列分成六類：可新增指派、已是同一老師不需變更、已有不同老師屬於重派、組別不存在或未成立或已解散、老師不存在或停用（含誤用聯絡 Email）、同一組在檔案中重複。有錯誤列就不能執行；重派列要 A1 明確確認並填理由。執行時一列一列做，某列失敗不影響其他列；預覽後被別人動過的組會回「請重新預覽」；結果表逐列顯示，失敗列可以重跑。通知只發給真正變更的組與老師。
- **做到哪裡**：本票交付 CSV 解析與驗證、六類預覽頁、逐列執行（沿用 S06-05／06 的單組用例）、結果表、重跑。CSV 原檔是否保存未定，不在本票；六類定義以產品 §5.4 為準，待 Roy 在 review 時確認。本票目前是「可操作功能」。
- **Roy 如何確認**：staging（或 local）；用 A1 與 S01；要先有 G1（已指派 T1）、G2（已指派 T2）、一個未指派的組 G4、一個已解散的組、一位停用老師 TX；準備一份含六種情況的測試 CSV；從管理員後台 → 組別 → 批次指派 CSV。

  | 操作 | 預期看到 |
  |---|---|
  | A1 不選屆別直接上傳 | 被拒，提示先選屆別 |
  | 選屆別、上傳測試 CSV | 預覽表每列標出六類之一：G4→可新增、G1＋T1→不需變更、G2＋T3→重派、已解散組→錯誤、TX→老師停用、重複的 G4→重複列 |
  | 直接按「執行」 | 被拒，提示有錯誤列不能執行 |
  | 刪掉錯誤列重新預覽，對重派列勾確認並填理由，按執行 | 結果表逐列顯示成功；G4 列主指導出現、G2 變 T3 |

### S06-10 [模組03 分組、指導與產學] 組長在三個條件下自行改組別類型，否則交系辦處理關聯後才能改
