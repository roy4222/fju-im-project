# 前端慣例（規格④ 外觀與響應式，C4-10 同步）

> 這份只在 repo（不是 Vault 的鏡像）。白話：寫畫面和動態特效時，下面幾條照做，Review 也照此檢查。路徑與數值都核對過 2026-10-21 的 `stage-c`。

## 1. 不准輸出 `style=`

網站的內容安全政策（CSP）沒有 `unsafe-inline`，`style="…"` 屬性會被瀏覽器擋掉。

- 樣式一律用 class；要動態的值（位置、顏色參數）用 `data-*` 屬性帶進去，由程式讀。
- 非要在程式裡動態設值，用 CSSOM：`el.style.setProperty('--fb-x', …)`（例：`web/src/app/_ui/fx/flying-button.tsx`、`fuzzy-engine.ts`），不是 JSX 的 `style={…}`。
- canvas 大小用 `width`／`height` 屬性，不用 CSS 內嵌。
- 有單元測試守門：多個元件測試（例 `web/src/app/dashboard/_stage.test.ts`、`web/src/app/_ui/auth-stage.test.ts`）會斷言輸出裡沒有 `style=`；e2e 的 `hero.spec.ts` 也量 `[style]` 為 0。

## 2. 觸控目標：`pointer-coarse:`

手指點的裝置（`pointer: coarse`）上，按鈕和連結的可點範圍至少 44px（Tailwind 的 `pointer-coarse:` 變體）。滑鼠裝置的外觀不變。

- 共用按鈕：`web/src/app/_ui/ui/button.tsx` 的 `lg` 加 `pointer-coarse:min-h-11`、`icon-lg` 加 `pointer-coarse:size-11`。
- 頂列的單顆元件各自加：`dashboard-frame.tsx` 的側欄開關、`dash-theme.tsx` 的主題切換、`inbox-bell.tsx`、`account-menu.tsx`、前台 `site-header.tsx` 的選單鈕。
- 字不變大、只放大點擊範圍時，用 `pointer-coarse:-my-3 pointer-coarse:inline-flex pointer-coarse:min-h-11 pointer-coarse:items-center` 這類寫法（例：`login/login-card.tsx` 的連結）。
- 頁面裡手寫的列內小按鈕，新寫的時候自己加。

## 3. 動態特效：共用 `fx/frame-loop`

所有 canvas／WebGL 動態都放在 `web/src/app/_ui/fx/`，迴圈統一走 `frame-loop.ts` 的 `startFrameLoop(el, tick, options)`，不要自己寫 `requestAnimationFrame`。

- `tick(dt, now)` 最多每 `1000 / fps` 毫秒呼叫一次（`fps` 預設 30）。
- 它自己處理：畫面外暫停（IntersectionObserver）、分頁隱藏暫停、回來時從頭起、不補播錯過的幀。`onRunningChange` 給 `data-running` 用，`onPauseChange` 讓引擎丟掉進行中的動畫。
- `env` 參數可換成假的，單元測試（node 沒有 rAF）靠它：`frame-loop.test.ts`。
- 現有使用者：`pixel-canvas.ts`、`letter-glitch.tsx`、`fuzzy-engine.ts`、`flying-button.tsx`。
- **減少動態一律退路**：`prefers-reduced-motion: reduce` 時不掛 canvas、不下載引擎（用靜態圖或靜態文字取代）。裝置條件用 `media-query.ts`：`useFxAllowed()`（hover＋精準指標＋沒減少動態）、`usePixelTouchAllowed()`（粗指標＋沒減少動態）。
- 引用 React Bits 的程式要保留授權註解（MIT＋Commons Clause，Copyright 2026 David Haz）。

## 4. 特效要「點開／條件符合才下載」

特效的引擎不准進首載（全站每條路由都會被拖大）。

- 載入函式只在 `web/src/app/_ui/fx/lazy-loaders.ts` 宣告（`loadBrokenFx`、`loadHomePixel`、`loadFlyingButton`、`loadStaggeredMenu`、`loadEasterEgg`、`loadPixelMedia`）；是否下載由使用處的互動與 media query 決定。
- `not-found.tsx` 不准放 client 元件；404／403 的「壞掉」頁由頁首的載入器看到 `data-broken-fx` 才載特效。
- 延遲載入的 UI（視窗、選單）要處理「下載期間的互動」：連點不能開兩個、計時照點擊當下算、關閉後焦點回觸發鈕。e2e 用 `page.route` 卡住 chunk 來測。
- 打包預算看 `web/scripts/perf/README.md` 的 `perf:bundle`。

## 5. 版面斷點

- 後台側欄：1024px 起常駐（`lg:`），以下是抽屜；`use-mobile.ts` 的 `MOBILE_BREAKPOINT` 也是 1024。
- 後台「現在」橫幅：1024 起分兩欄，768～1023 單欄。
- 前台頂列：1024 以下收成選單；登入後頂列要 1280（`xl:`）才放「我的後台」。
- 橫向捲動的資料表用 `web/src/app/_ui/ui/table.tsx` 的 `table-scroll`（邊緣陰影提示；`stickyFirst` 固定第一欄）；既有的 `overflow-x-auto`／`overflow-auto` class 不要拿掉（e2e 靠它們找元素）。
