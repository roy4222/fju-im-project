# 學生 Dashboard 拋棄式 UI prototype

這是一份可直接比較三種資訊架構的本機原型。所有姓名、學號、組別、日期、文件、版本與回執皆為虛構資料；沒有後端、登入、資料庫或真實送件行為。

## 開啟方式

直接雙擊 `index.html`，或用下列網址參數指定版本：

- `index.html?variant=A` — Timeline／截止日優先
- `index.html?variant=B` — 待辦狀態工作區優先
- `index.html?variant=C` — Kiranism 式側欄＋快捷卡＋工作清單

頁面底部固定顯示「原型切換器」。可按 A／B／C、左右按鈕，或直接使用鍵盤 `←`／`→` 切換；切換不會重新載入頁面，所以模擬狀態會保留。

## 可操作內容

- 依待完成、草稿、需重送、已繳交、已逾期篩選工作。
- 展開共用草稿版本，切換 v1–v4 檢視狀態。
- 模擬本人同意、草稿儲存、送出與補正重送，並查看可見回執。
- 將待辦切換成草稿狀態。
- 切換深色／淺色主題。
- 原型 C 在窄螢幕可開啟收合側欄。

每一版都提供 `PROTOTYPE STATE` 面板，顯示目前版本、主題、篩選、草稿版本、同意與送出狀態。所有互動只保存在頁面記憶體中；重新整理即可重置。

## 比較問題

1. 五秒內是否看得出下一個截止與下一步？
2. A 的時間壓力、B 的工作狀態、C 的完整工作台，哪一種最符合學生心智模型？
3. 在 390px 手機與 1440px 桌機上，重要資訊是否仍維持在前段？

本原型刻意排除成績資訊與商業分析指標，只呈現專題流程所需的工作、分組、簽核、公告與版本狀態。

## Smoke check（2026-08-17）

- A／B／C 在 1440×1000 實際渲染，390×844 可由鍵盤從 C 切到 B；無 runtime／console error、外部 request 或頁面級橫向溢位。
- 實際操作 `需重送` 篩選、深色主題、展開版本並切換到 V2，`PROTOTYPE STATE` 均同步更新。
- 驗收時曾發現 `<html data-variant>` 讓事件代理誤攔所有 click；已將 selector 收窄為 `.variant-btn[data-variant]` 並重跑通過。
