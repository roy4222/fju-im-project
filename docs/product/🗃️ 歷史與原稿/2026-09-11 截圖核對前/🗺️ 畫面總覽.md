# 🗺️ 畫面總覽（原型 2026-09-11）

| 產品行為 | 模組 | 說明 |

| 老師首次登入補資料、停用後被拒、永久刪除影響預覽 | 01 | 只有規則與案例 |
| 建立屆別、封存、下一屆、模擬業務日期、活動改期取消 | 02 | 原型日期寫死 |
| 組長提案與成員逐一確認、拒絕、例外組建立表單、解散影響預覽 | 03 | 原型只有狀態顯示 |
| 收件單位選個人／組別、有回答後改結構的新版本、撤回、下架、Tiptap 富文字 | 04 | 原型一律整組一份、Markdown |
| 個人填報畫面、送出回執（收件章）、並發衝突、上傳被拒 | 05 | 回執在程式中有，自動操作截不到 |
| 指派評分老師、匯出、方案套用重算預覽 | 06 | |
| 例外組人數、舊頁被拒、換老師失權 | 07 | 文案固定五人 |
| 已讀跨登入、去重、連結重驗權限 | 08 | Email 與外部日曆延後 |
| 未授權下載被拒、上傳錯誤、備份還原狀態 | 10 | |

## 原型與規格明顯不一致（已列在各模組第 0 節）

側欄仍有獨立「內容編輯器」；合作案有「網際網路公開（含聯絡資訊）」；所有收件都是整組一份；忘記密碼與各回執寫「寄信」；首頁有「訂閱到 Google 日曆」；學生成績頁寫「v1」；簽核文案固定「五位」；檔案用量寫 200 GiB。這些都不改產品決定，等正式版實作時處理。
