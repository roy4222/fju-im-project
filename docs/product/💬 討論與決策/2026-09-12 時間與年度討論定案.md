# 2026-09-12 時間與年度討論定案

來源：本日 Roy 與 Claude（Fable）grill-with-docs 第四輪，七題。Roy 逐題以補充邊界後的版本確認；Q6 不採 Fable 的「只能一屆進行中」。這些是產品決定，不代表功能已實作或驗收。repo `docs/product/` 鏡像在本輪全部討論結束後一次同步。

## 已決定

| 題 | 決定 | 取代／影響 |
|---|---|---|
| Q1 解散後閱覽權 | 以解散當下仍有效的授權轉成限定範圍唯讀：學生只看成員快照含自己的正式繳交版本及附件；老師只看當時仍有權閱讀的組別正式版本與自己有權查看的評分；主指導身分不授予其他老師的評分、不開放個人問卷。被移出、重派或撤權者不因解散恢復；停用仍禁止；頁面與下載同規則；學生看不到成績。 | 模組 03 §5.5；新增 GRP-20 |
| Q2（Q-PUB01）空收件 | 收件至少一個可填寫欄位或一項上傳要求，兩者皆無不能發布；提示「新增填寫欄位或上傳要求，或改用公告／資源」。簡單確認用必勾選欄位，點選紀錄表示本人確認；驗證實際到場是另一項需求。 | 模組 04 §4；PUB-13 改寫 |
| Q3（Q-PUB01）時間邊界 | 全站臺灣時間；開放與截止精確到分鐘，期限到截止分鐘的下一分鐘之前（23:59:59.999 可、00:00:00 不可），不用 23:59:59 當界線。詳細畫面寫「截止：2026/11/15 23:59（含此分鐘，臺灣時間）」，列表可簡寫，表單說明、回執、匯出可確認時區。準時以後端收到完整正式送出請求的時間判定，附件須已完成上傳；按鈕或開始上傳不算，以成功回執為準；舊頁面重新檢查期限、資格與封存。 | 產品總規格 §4；模組 04 §4；模組 05 §4.6；SUB-16 |
| Q4（Q-PUB01）階段 | 選 A：階段是連續的年度主進度，每階段只填開始日、嚴格遞增；下一階段開始日 00:00 起不屬上一階段；年度結束日含當天至隔日 00:00。第一階段前顯示「尚未開始」，年度結束後顯示「年度階段已結束」；不無限延長最後階段，不自動封存。年度劇本的四階段只是測試資料。 | 模組 02 §4、§6；COH-01；年度主線 §1 |
| Q5 收件期限與階段 | 收件期限獨立於階段，但其他受階段限制的操作照各模組規則。收件截止必填；開放預設發布即開放並記下實際開放時間，修改或重新發布不默默重設；截止不得早於開放；收件明確設定所屬階段，延長截止不自動改分類；指定重開仍受資格、停用、解散與封存限制。 | 模組 02 §4；模組 04 §4、§6；新增 PUB-14 |
| Q6（Q-COH01）屆別 | 三狀態籌備中／進行中／已封存；允許多屆同時進行中，另指定一個預設工作屆別與一個開放註冊屆別。學生預設看自己屆別；老師與管理員可切換，畫面與操作預覽標示屆別，佇列不混。籌備屆做註冊、核准、設定，轉進行中不要求先封存上一屆。封存前列未完成並填理由，可帶未完成封存，原狀態照實保留；封存後各角色不能改該屆業務資料。管理員填理由可解封，不受另一屆限制；解封不延長期限、不恢復撤銷關係、不重送通知；紀錄與快照保留，再封存另留紀錄。 | 模組 02 §11.3、§5、§6、§8；COH-01／05／06／09 改寫；CONTEXT 新增屆別狀態、預設工作屆別；不採「只能一屆進行中」 |
| Q7 模擬業務日期 | 可前進可倒退，設定到秒；每次記錄操作者、原因、真實時間與前後業務時間；正式版本與紀錄同時保存真實與業務時間。回撥後仍合資格且未封存的收件可重新送出；不讓作廢提案復活、不取消解散、不解除封存、不撤回通知。前進跨過截止執行截止處理；反覆跨過同一期限不重複通知、不覆寫截止快照。主線持續往前，回撥只用於標記的邊界測試或局部重跑，不等於還原資料、不能拼主線。 | 模組 02 §4；COH-04；新增 COH-10 |

## Fable 的口誤（已更正）

Fable 在第四輪開場把驗收前提說成「只 seed 一屆測試資料」。正確前提一直是年度主線第 5 行：只 seed bootstrap 管理員 A1，115-TEST、其他帳號、組別與項目由實際介面建立，最後再建 116-TEST 驗證跨屆隔離。文件本身沒有寫錯，這裡記下避免再誤傳。

## 工程備註

- 階段以「開始日清單＋年度結束日」保存，判定用臺灣時間的日界；收件期限用到分鐘的時間點，比較用「小於下一分鐘」。
- 每筆正式版本、通知與稽核同時存真實時間與業務時間；模擬日期只注入業務時間來源。
- 屆別切換是老師與管理員的介面狀態，授權仍逐請求依所屬屆別判定；預設工作屆別與開放註冊屆別是屆別上的兩個單一旗標。
