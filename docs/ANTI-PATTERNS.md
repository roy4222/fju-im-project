# UI 反樣式清單（硬約束）

> 這份文件的來源：2026-08-17 Roy 對前一版原型的評語是「**太 AI**」。
> 下面每一條都是從那一版的實際畫面反推出來的病灶，不是通則。
> 前一版的畫面保留在 `docs/_archive/codex-open-design-prototypes/screenshots/` 供對照。
>
> **每個新畫面完成後，逐條自檢。**

## 一、文案

1. **禁止行銷式標語當標題。** 反例（實際出現過）：「專題，不只是一學年的作業。」「把好作品留在下一屆找得到的地方。」「真實問題，成為學習的起點。」
   正解：名詞性標題——「最新公告」「近期截止」「歷屆專題」「產學合作」。
2. **禁止句式**：「不只是…」「讓…成為…」「…的起點」「…的地方」，以及任何以句號結尾的區塊標題。
3. 這是**學校官方子站**，語氣是公告，不是品牌行銷。訪客來這裡是要**找資料**，不是被說服。

## 二、視覺

4. **禁止裝飾性 gradient、blur、glow、同心圓、光暈、噪點。** 前一版每個 hero 都有一組漸層同心圓——那是 LLM 生成 landing page 最明顯的指紋。
   顏色只能來自 `globals.css` 的 token；漸層僅在有功能理由時使用（例如 Data Table 水平捲動的邊緣提示，見 MOC §10.3）。
5. **中文標題禁用襯線體。** 前一版用大字 serif 做 hero，氣質完全偏離系網。
6. **禁止 emoji 當 icon。** 一律使用 `@tabler/icons-react`。
7. **禁止「一句標語 ＋ 三張卡」的區塊節奏無限重複。** 前一版首頁五個區塊全是這個結構，滾動 4282px 只呈現了 5 則公告與 3 件作品。

## 三、資訊密度

8. **首頁密度基準：桌機首屏（1440×900）內必須看到實際內容**，不是只有一個 hero。系網本身就是一頁塞滿公告列表的機關網站。
9. **列表預設顯示筆數要夠。** 公告類區塊至少 5 筆可見（MOC §9.2 說「最新／精選三筆」是下限，不是上限）。
10. **禁止為了留白而把可用資訊移到第二屏。** 近期截止日、待辦數量、公告標題屬於第一屏。

## 四、元件

11. **禁止手刻 CSS 模仿 shadcn 外觀。** 一律 `pnpm dlx shadcn@latest add <component>`。前一版是單檔靜態 HTML 手刻 CSS，導致 Data Table 的 sticky header、固定欄寬、ellipsis + tooltip、水平捲動全部無法驗證。
12. **大型名單一律使用 Data Table（TanStack Table）**，不得用 `<div>` 排格線假裝表格。規格見 MOC §10.3。
13. **每個列表都要有五種狀態**：空白、載入、錯誤、無權限、沒有搜尋結果——必須長得不一樣（MOC §10.3）。

## 五、Dashboard

14. **第一眼回答「我現在要做什麼」，統計數字排在後面**（MOC §10.4）。
15. **禁止假數據圖表**：營收、訂閱、MRR、轉換率、成長曲線一律不得出現（MOC §3.6 明列）。圖表只能呈現真實業務量——完成率、逾期數、評分進度、儲存量。
16. **禁止 donor 的無關功能**：billing、kanban、chat、ai-chat、org switcher（MOC §10.1）。

## 六、可存取性（MOC §14.2，目標 WCAG 2.2 AA）

17. 不移除 focus ring。
18. icon-only 按鈕必須有 `aria-label`。
19. 內文與底色對比 ≥ 4.5:1；深色主題同樣要驗。
20. 觸控目標 ≥ 44×44px。
21. 動畫尊重 `prefers-reduced-motion`。
22. 360px 寬度仍可完成核心流程。
