# 參考站設計摘要（2026-09-07 實際截圖）

來源：規格 §19.1 與 §19.3 列出的網址，用本機 Chrome 1440 寬全頁截圖。

## 1. 系網 im.fju.edu.tw（品牌基準，最重要）

### 版面節奏
- 首屏：全寬照片輪播，深藍疊色，白字標題＋人物照。**不是文字 hero**。
- 之後每一區都是「大標 → 內容 → 置中的橘色外框『查看更多』」。
- 區塊版型交錯，不重複：
  - 招生訊息：左邊兩張照片卡，右邊四則純文字列表（日期＋標題＋橘框標籤）。
  - 得獎焦點：四欄照片卡。
  - 產業實習：左邊四則列表（深藍左側粗線），右邊一張大照片。
  - 影音專區：影片縮圖輪播。
  - 最新公告：分類 tab（重要公告／招生訊息／獎助學金／榮譽榜／企業徵才／學術活動／行政相關）＋四欄卡。
  - 學生園地／系所簡介／相關連結：三欄連結群組，底圖是淡出的校園照。
- 區塊之間留白很大（約 120px 以上），整頁很長。

### 字體與標題
- **全站黑體**，粗體標題。沒有任何襯線體。
- 區塊大標的寫法：第一個字橘色、其餘深灰，例如「**得**獎焦點」「**產**業實習」「**最**新公告」。置中或靠左都有。
- 靠左的大標放在一塊淺灰藍、右上大圓角的底板裡，旁邊直接放橘色實心「查看更多 →」按鈕。

### 卡片
- 照片在上（約 16:9），下方是暖白底 `#FFF4EA`，圓角約 12px，柔和陰影。
- 內容順序：日期（灰、粗）→ 標題（黑體粗、可多行）→ 橘色外框標籤（可多個）。
- 沒有照片的卡片，上方留白區塊維持同高，不塌。

### 列表
- 深藍 `#003366` 左側粗線（約 5px、圓角），標題粗體、日期灰色小字，項目之間留白。

### 顏色
- 深藍 `#003366`：header 底、footer 底、列表左線、部分文字。
- 橘 `#E56E00`：導覽選中、大標首字、按鈕、標籤外框、「查看更多」。
- 淺灰藍：區塊標題底板。
- 暖白 `#FFF4EA`：卡片底。
- 背景交錯：白 → 淡出校園照 → 白。

### 對新站的意義
- 現況首頁的問題：文字 hero、每區「置中標題＋三卡」重複、灰佔位圖、宋體標題。四項都和系網相反。
- 應該做的：照片 hero（沒照片時用深藍底＋校徽紋理也比灰框好）、區塊版型交錯（列表／卡片／圖文左右）、黑體標題＋橘色首字、卡片用暖白底、列表用深藍左線、每區「查看更多」統一做橘色外框寬按鈕。

## 2. 舊專題站 project.im.fju.edu.tw（流程與內容參考，不沿用 UI）

- 導覽：首頁、申請帳號、公告欄、專題規則、產學合作列表、檔案下載、登入。
- 首頁：照片輪播 → 左「最新消息」表格（近五年的「第 N 屆專題系統發表優秀組別」）＋右「檔案下載」→ 「專題施行概要」六格（課程目的、進行規則、修課限制、評分方式、題目及範圍、評分比例）。
- 產學合作列表：一張表，欄位是編號／公司名稱／需求部門／申請日期／指導老師／詳細資料。**21 筆真實資料**，公司名稱被截斷（如「日本山梨縣立大學(Yamanashi P」），印證規格 §6.2「放寬字數限制」。
- 產學詳情：公司名稱、需求部門、單位連絡人、連絡 email、專案性質或內容、需求或具備條件、備註。**連絡人與 email 目前是公開的**，新站規格改為老師本人＋管理員可見。
- 專題規則：九個手風琴（課程目的、修課限制、題目及範圍、分組與選指導老師、轉組、上課方式、課程要求、評分方式、獎懲方式）。這九節是規則頁的內容大綱。
- 「我的學生」需登入，未截到。

## 3. TronClass 支援文件（作業與成績的行為參考）

- 作業：老師設繳交次數與截止後補交；學生多次繳交保留歷史版本（「批改」→「繳交歷史紀錄」）；老師可打包下載全班作業；未評分前學生看不到評語。
- 成績：老師可設定「不公佈」；成績送繳後鎖定；各學習活動佔比總和不能超過 100%；「原始成績」與「最終成績」分開，最終成績可手動改，建議在備註寫原因。
- 對應規格：§4.6 版本與重送、§7.4 暫存與鎖定、§7.5 管理員更正保留原值與理由、§7.6 學生不看成績。TronClass 的做法印證規格方向，沒有衝突。
