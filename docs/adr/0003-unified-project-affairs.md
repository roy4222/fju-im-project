# 事務共用模型，前台保留不同用途入口

原需求將公告、檔案、繳交與專題需求列為不同業務，若各自建立編輯、附件及生命週期，會重複管理相同內容。8/17 主規格決定以專題事務項目統一後台的內容、欄位與檔案模型，一筆內容選一個主要發布位置，前台仍分用途顯示；Dashboard 與首頁引用同一來源。這減少重複內容與多套 CRUD 的維護，但必須明確處理 audience、欄位版本及整組共用草稿／正式快照；個人註冊與本人同意維持獨立固定流程。
