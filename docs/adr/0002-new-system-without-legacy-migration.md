# 全新系統，不遷移舊業務資料庫

舊網站保留流程與內容參考價值，但新平台不以取得、改造或相容舊系統為前提。8/17 主規格選擇全新 repo、身分與資料模型，不沿用舊碼、不遷移舊帳號／組別／繳交／成績資料庫，也不接 LDAP；值得公開保存的歷屆成果由管理員人工精選補登。這放棄自動延續舊資料與帳號的便利，換取清楚的新資料與身分邊界，並留下人工補登的工作成本。

來源：[完整主規格](<../product/📋 完整產品規格.md>) §1.4、§9.1、§11.3、§20；2026-09-06 Roy 指示沿用既有規格並抽出文件。本 ADR 是追溯記錄既有決定，不代表實作、部署或校方驗收已完成。
