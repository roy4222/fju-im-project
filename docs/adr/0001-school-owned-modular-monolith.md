# 校方自有環境中的單一應用

公開站、角色 Dashboard 與管理流程共享身分、組別、內容和版本資料，且核心資料與檔案需由校方掌握。8/17 主規格選擇單一 Next.js modular monolith，搭配 PostgreSQL、校內 VM 檔案 volume 及 Docker／Compose；不將 donor 另行部署為產品，也不引入微服務、Kubernetes、MinIO 或多雲。這個取捨保留單一業務與部署邊界，同時由校方承擔 VM、資料／檔案成對備份與還原責任；外部備份目的地仍待封板。

> **2026-09-12 補充（不改當時決定）**：本 ADR 所述「資料／檔案成對備份與還原」與「外部備份目的地待封板」已被 2026-09-11 Roy 決定取代：只備份資料庫到 Cloudflare R2（每日、加密、保留 30 天），VM 本機快照 7 天，附件不做異地備份且 Roy 已接受此風險。現行規則見 [產品總規格 §6](<../product/📐 產品總規格.md>) 與 [共用契約 05](<../engineering/contracts/05 CI-CD、部署與維運.md>) §6；單一應用與校方 VM 的決定不變。

來源：[完整主規格](<../product/📋 完整產品規格.md>) §1.1、§11、§13、§20；2026-09-06 Roy 指示沿用既有規格並抽出文件。本 ADR 是追溯記錄既有決定，不代表實作、部署或校方驗收已完成。
