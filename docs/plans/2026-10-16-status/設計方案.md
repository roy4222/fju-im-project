### 3.2 淺色／深色跟系統（0 JS）

`status/src/components/globals.css:5` 現在是 `@custom-variant dark (&:is(.dark *));`，`:135` 是 `.dark { … }` 色票區塊；整個專案沒有任何東西會掛 `.dark` class，所以永遠是淺色。改法：

```css
/* 刪掉 :5 的 @custom-variant dark (&:is(.dark *)); —— Tailwind 4 的 dark 變體預設就是 prefers-color-scheme */
@media (prefers-color-scheme: dark) { :root { /* 原 .dark 區塊的變數，原樣搬進來 */ } }
```

既有 `dark:` 工具類全部沿用；`<html>` 加 `color-scheme: light dark`（表單控件、捲軸跟著變）。不加切換鈕、不存偏好、不加任何 client JS（Q98：跟系統）。
