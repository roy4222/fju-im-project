# 白話版：公告與作業・交作業・同意書・評分 這次會變成什麼樣

給 Roy 看的。每個畫面一段「現在 → 之後」，照你 10/18 走查定案表的編號。想改哪個，直接在 Obsidian 標我。

## 系辦：公告與作業

**新增／編輯（A11、A3、A4、A5、R2）**
- 現在：按「新增項目」跳三步驟視窗（選類型 → 填內容 → 發布），要細調得再開「完整編輯器」，裡面四大段、還要選「所屬階段」，底下有紅色危險區。
- 之後：一頁搞定。左邊從上到下填：對象、開放時間、截止時間、標題、內容、附件、繳交欄位、進階設定（收起來）；右邊即時顯示「學生看到的樣子」。沒有「所屬階段」。底下只有兩顆鈕：「儲存（先不發布）」「發布」。少填必填欄位，當下就在欄位旁紅字提醒，不會等到最後才一大串。所有類型（公告、作業、資源、規則、榮譽）都是同一張表單，差別只是露出哪些欄位；之後前台直接編輯（規格②）也是開這張。

**每個分頁一顆「新增」（A1、A2、A10）**
- 現在：所有類型混在一張清單，右上「新增項目」＋「完整編輯器」。
- 之後：在「公告」分頁按「新增」就是新增公告，在「作業」分頁按就是新增作業（下拉可選「同意書」）。沒有完整編輯器。

**作業分頁與繳交狀況（A9、A23）**
- 現在：清單看不到進度；刪不掉要按了才知道原因；催繳要自己寄信。
- 之後：清單每列「標題｜對象｜截止｜繳交進度條（3／8 組已交）｜編輯｜刪除」。不能刪的，按鈕本身寫原因（「發布中，先下架才能刪」）。點進去是繳交狀況：名單有頭像、誰交了誰沒交，頂部一顆「催繳未繳（N 人）」，按了站內通知＋Email 一起發；同一份 24 小時內只能催一次，按鈕會寫「幾點後可再催」。免繳、補交的理由都改成選填。

**繳交欄位用拖拉（A13）**
- 現在：欄位只能用上下移鈕排。
- 之後：每列有拖柄可以拖、也保留上下移（鍵盤可用）。欄位種類：短文字、長文字、單選、複選、下拉、檔案、日期、說明文字，更多在「更多型別」裡。檔案欄可選檔案種類與大小上限，學生那邊會自動顯示「PDF・20 MB 以內」。已經有人交過的作業，欄位結構鎖住只能改欄名。不裝任何拖拉套件（頁面大小快到上限）。

**專題規則（A3）**
- 現在：清單＋上下移，編輯要進完整編輯器。
- 之後：一頁列出全部章節卡片，可以拖著排順序；按「編輯」就在卡片裡展開改，存了前台 `/rules` 立刻跟著變。

**成果展示（X1）＋榮譽榜**
- 現在：頁面上方兩塊表單、每件作品展開有四顆存檔與危險區；榮譽在另一頁。
- 之後：只有一張清單（海報小圖、題目、組別、獎項、首頁順序），按「編輯」開一個小視窗改完存一次。榮譽榜在同一分頁下半。右上「新增」下拉：作品／補登歷屆／榮譽。

**檔案**
- 現在：只能看。
- 之後：多一欄「用在哪裡」；沒人用的檔案可以刪，有人用的按鈕寫「還有 N 處在用」。不做上傳（檔案都是跟著公告或作業上傳的）。

## 學生：交作業（S4～S8、R1）

- 現在：清單篩「待交／已交／逾期」；作業頁有「儲存草稿」「代表全組正式送出」兩顆；超大檔案要等上傳才被擋。
- 之後：清單欄「名稱｜形式（檔案／表單／同意書）｜狀態｜截止｜交作業」，**沒有成績欄**（學生看不到分數是既定）。作業頁兩個分頁「作業內容｜繳交歷史」，繳交歷史只列正式送出的紀錄（時間、誰交的＋頭像、查看）。按「寫作業」填表上傳，只有一顆「繳交作業」。選到 25 MB 的檔當下就紅字「超過 20 MB 上限」，不會上傳。沒有「儲存草稿」鈕，但上傳完的檔案會自動記住，下次回來還在。未分組的學生看不到整組作業，也不會收到通知（維持現狀）。

## 老師：作業區（T3）

- 之後：多一個「我的作業」分頁，跟學生同一套畫面。系辦可以發作業給老師，例如「指導意願調查表」。老師原本看各組繳交的總表不動。

## 同意書（A12、S8、#161）

- 現在：在「成績 › 同意書」逐組建版本；學生頁面有版本號、文件檢查碼、登入方式、校方是否接受一堆字。
- 之後：同意書是**一種作業**。系辦在作業分頁「新增 › 同意書」有兩種：
  1. **站內表單**：貼全文、選對象（本屆學生或指定組）、發布 → 系統自動替每個有指導老師的組建立同意書；沒老師的組會寫「尚未建立：沒有指導老師」，等指派後按一下「建立」。用途選「最終文件授權」時，每個對象組都要先有成果展示草稿（它會把題目、摘要凍結進同意書），缺的話會列出組別、不讓你發布。
  2. **下載 PDF 再上傳**：附上空白 PDF，學生簽好上傳，就是一般作業。
- 學生那邊：在「交作業」清單看到形式「同意書」，進去是「說明｜狀態」。狀態分頁一張「全組狀態」表：每個組員頭像、已同意／還沒表態，最後一列是老師；自己那列有「我同意」「不同意」（不同意可以不寫理由；老師退回、系辦重新收集也都不強迫寫理由）。版本號、檢查碼全部不顯示（資料留著、系辦匯出看得到）。
- **系辦改了同意書內容（#161）**：按「儲存更新」，每一組自動建新版，**所有人（包含已經同意過的學生和老師）都收到「同意書內容已更新，請重新閱讀並同意」**，進度歸零、每人重投；舊的同意留在歷史與匯出裡，但不算新版的票。只改截止或對象不會這樣。
- 原本的「同意書」側欄分頁消失（搬進作業；舊網址會轉過去）。

## 評分（T2、T2-1、T2-2、T2-3、X5、A27）

**資料怎麼接**：現有的「計分階段」就是你說的「評分項目」，階段底下的「項目」就是「細項」。一組有幾個評分項目就有幾份成績；要幾位老師評（例如 3 位）各評一份，系辦看平均再結算 — 這些 B 階段已經有了，不動。只加兩樣：每個評分項目可以「對應一份作業」（老師批改時左邊就看那份作業的檔案）或「不對應」（只有標題＋說明，直接填分）；兩樣改了都不用建新版、不會把已填的分數鎖住。

**老師評分（T2）**
- 現在：清單 → 兩欄批改頁，繳交清單是該組所有作業。
- 之後：清單每個評分項目一區，每組一列「組別｜狀態｜附件（2 個檔案・m/d 交）｜成績｜批改」。批改頁三欄：左邊是我負責的組清單＋上一組／下一組＋繳交版本下拉＋檔案；中間直接看 PDF；右邊填分（必填）＋評語（選填）＋「送出」。沒對應作業的項目，中間顯示項目說明和「直接填分」。「儲存草稿」留著（你說要拿掉我再拿）。

**系辦成績（X5、A27、X2）**
- 現在：成績管理一頁塞滿；「尚缺 x 位評分老師」是純文字。
- 之後：四個分頁「成績表｜評分規則｜評分老師｜結算」。成績表的「尚缺 2 位評分老師」紅字是連結，點了跳到「評分老師」分頁、捲到那組那一列，旁邊就是「＋指派」。評分規則頁可以自己加減評分項目、細項、滿分、比例（**實際有哪幾項、各幾 %，規格不寫死，你在後台調**），每個項目可以選對應哪份作業、填說明，也可以把兩個項目（例如驗收與總評）設成「同一組評審」：之後指派一次兩項一起動，兩邊老師永遠一樣。老師在批改頁只看得到自己項目對應那份作業的檔案，別的作業的附件連網址直接打都拿不到。結算、更正、改派的理由都改選填；只有「退回評分」還是必填（老師要看到原因）。

**前台專題規則（X7）**
- 現在：規則正文寫死「系統驗收 60%、專題發表 40%」。
- 之後：規則頁末尾固定一段「評分方式」，直接讀後台評分規則；你在後台改比例，前台自動變。

## 系辦首頁待辦卡（A9）

- 之後：「逾期未繳」卡與「評分還差 N 份」卡各多一顆「催繳」。按了對每份逾期作業的未交者、或每位還沒送齊的老師，各發一則站內通知＋Email；24 小時內催過的會略過並告訴你。

## 示範資料會怎麼搬

- 測試站凍結期間：整組刪掉重灌一次。灌回來多三筆：一份給老師的「指導意願調查表」、一份「專題成果授權同意書」（就是原本那 6 組的最終文件授權同意書與 28 票，全部掛到它底下，狀態不變）、一份「系統驗收文件」作業（3 組已交有 PDF，對應到「系統驗收」評分項目，讓老師三欄頁有東西看）。規則正文裡的 60／40 數字拿掉，改讀評分規則。

## 這次刻意不做

- 不裝拖拉套件、不裝 PDF 套件、不加 Markdown 套件（頁面大小快到 250 KB 上限，而且現有的 Tiptap 打 `# `、`- ` 就會自動轉）。
- 不改評分的計分表結構、不把同意書的票搬成作業繳交紀錄（兩邊都有法律與測試意義）。

- 側欄、分頁外殼、前台直接編輯的入口是規格②；分組、頭像、專題時程是規格③。
