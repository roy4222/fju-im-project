# C 階段規格①「公告與作業・交作業・同意書・評分」— 驗收案例

- 每條四欄：前置狀態／操作／預期可觀察結果／**在目前版本（`stage-b` = `69116fc`）上會怎麼失敗**。最後一欄標「既有保證」的，表示目前已經這樣、本份不能弄壞；標票號的，表示要等那張票合進 `stage-c` 才會過。
- 「目前版本」指測試站示範資料（`scripts/demo/`）的狀態；帳號用示範帳號（系辦、老師、學生各一）。
- 對應票見 [拆票.md](拆票.md)；設計依據見 [設計方案.md](設計方案.md)（§ 編號）。
- 最後一條 AC-37 是端到端。第 2 版新增的案例用子編號（AC-21a、AC-28a…）插在對應區塊，既有編號與拆票引用不動。
