# 規格④ 驗收案例

- 欄位：前置狀態／操作／預期可觀察結果／在目前版本（`stage-c` `69116fc`）上會怎麼失敗。「既有保證」＝現在就通過、改完要繼續過；「依賴 X」＝要等某票。
- 瀏覽器預設 Desktop Chrome 1280×720；手機案例寫明 viewport 與 `hasTouch`。
- 減少動態用 `page.emulateMedia({ reducedMotion: 'reduce' })`；深色用頂列「切換為深色」。
- AC-66～AC-72 是 Review 後補的案例（骨架、常駐閃、前台觸控目標、帳號頁瘦身），放在各自段落；端到端案例固定是最後一條 AC-73。
