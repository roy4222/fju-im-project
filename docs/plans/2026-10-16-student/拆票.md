- 「會受影響的既有測試」欄列的測試全部跑過，PR 說明寫「跑了哪些、結果」；改了任何既有測試要在 PR 說明逐行列出並引用衝突表編號（C-ST-1～28），**不得改列表外的行**（尤其側欄斷言與老師／系辦段）。
- PR 說明附對應 AC 的驗證紀錄（截圖或 Playwright 輸出）；ST-1 另附 `todos.test.ts` 三個 `isCurrent` 反例的輸出；ST-2 另附 AC-ST-25 的方法呼叫次數（`vi.spyOn`）與 SQL 句數（qcount 做法）兩個數字；ST-6 另附 `calendar-model.test.ts` 的改期與取消案例。
- 沒有 inline `style`（`grep -rn "style={{" web/src/app/dashboard/student web/src/app/timeline` 為空）。
- 定案值（Q117～Q129）直接寫成程式與測試；PR 說明不再有「⏸ 待定」段落。
- 不開新的「待決」：遇到規格沒寫的，回報架構師，不自己決定。
