# 學生後台要改什麼（白話版）

日期：2026-10-16。這一頁給 Roy 看。細節在同資料夾的 `設計方案.md`、`驗收案例.md`、`拆票.md`。

## 一句話

學生登入後只看到三個地方：**首頁、交作業、組別**。首頁先告訴學生「現在是哪個階段、下一件要交什麼」。其他東西搬走或拿掉。

## 改前、改後

| 地方 | 改前 | 改後 |
|---|---|---|
| 左邊側欄 | 7 項：首頁、專題時間軸、通知、我的繳交、我的組別、產學合作、站內同意書 | 3 項：首頁、交作業、組別。通知從右上角鈴鐺進 |
| 首頁 | 進度條、四個階段格、三個小標籤、行事曆、「接下來」、公告 | 深藍橫幅（現在的階段、還有幾天、下一件要交的、「看完整時程」）、最多 5 張待辦卡、5 則公告 |
| 看時程 | 後台一頁「專題時間軸」 | 前台新頁 `/timeline`：階段軌＋整月行事曆。老師首頁也會連到這裡 |
| 交作業 | 表格，四個分頁：全部、待繳、已繳交、逾期未繳 | 卡片，三個篩選：待交、已交、逾期。卡片只有名稱、截止、狀態 |
| 同意書 | 側欄一項「站內同意書」 | 在「交作業」裡是一張卡（沒有截止日）。點進去同意 |
| 作業詳情 | 繳交歷史是表格；收件章寫「表單第 N 版」；「需要補交請聯絡系辦」 | 繳交歷史是時間線（第 1 次、第 2 次、採計）；不寫表單版本；不寫「請聯絡系辦」 |
| 組別 | 一長頁：狀態、產學面板、找組員、提案紀錄 | 三個分頁：我的組（組員頭像、組長冠冕、指導老師 Email、里程碑線）、找隊員、紀錄 |
| 產學合作 | 側欄有、後台有頁、組長可以改類型和連結合作案 | 學生這邊全部拿掉。改類型和連結交給系辦（和負責老師） |
| 成績頁 | 直接開網址看到一句「學生不會看到分數」 | 網址直接跳回首頁 |
| 「請聯絡系辦」這類句子 | 很多 | 都拿掉 |

## A 和 B 各做什麼

**A（10/18 18:00 前合併，只改畫面）**

- 首頁新版面、待辦卡、公告。
- 交作業的卡片與三個篩選、同意書卡。
- 作業詳情的時間線與文案。
- 組別三分頁、指導老師 Email、里程碑線（頭像先用名字圓形占位）。
- 前台 `/timeline` 頁。
- 三個舊頁轉址。
- Pixel Trail 滑鼠光點（共用做元件，學生首頁掛上去；只在滑鼠電腦、沒開「減少動態」時出現）。
- 側欄改三項、徽章改口徑：由共用規格做，學生這邊的測試先改好，順序不影響。

**B（10/19 之後）**

- 頭像。
- 組別頁的產學面板拿掉（等系辦的「連結合作案」對話框做好，同一天拿掉，不然中間沒人能連結）。
- Google Calendar 匯出或訂閱（另開）。

## 要請你決定的事（14 項，建議值在括號裡）

1. 「交作業」徽章要不要算逾期？（建議不算，徽章＝待交數；逾期在首頁用紅卡提醒）
2. 「快到期」是幾天內？（建議 10 天）
3. 「尚未開放」「免繳」的作業放哪個篩選？（建議：尚未開放放待交、免繳放已交）
4. 組別里程碑線有哪幾格？（建議：發起提案、成組，再加每件整組要交的作業）
5. 組別頁的產學面板 A 就拿掉，還是等系辦對話框好了再拿？（建議等 B，不然中間沒人能連結合作案）
6. 「以前的紀錄」（被移出名單後還看得到自己交過的）要留嗎？（建議留，放「已交」下面）
7. 指導老師卡顯示哪個 Email？（建議老師自己填的聯絡信箱）
8. 同意之後，同意書卡算「已交」？作廢的版本要不要列？（建議算已交；作廢不列）
9. 首頁待辦不到 5 張時，用最近已交的補滿嗎？（建議補滿）另外：首頁不再顯示組別與指導老師，改到「組別」頁，可以嗎？
10. `/timeline` 要不要放進前台頂部選單？老師看時要不要列學生截止？（建議不放；老師先只看階段和活動）
11. 三個舊網址跳去哪？（建議：成績→首頁、後台產學→前台產學、後台時間軸→`/timeline`）
12. 逾期作業頁要不要留一句「可向系辦申請補交」？（建議要，一句就好）
13. 卡片要不要標「整組」？系辦開了補交期限的，截止字用新期限？（建議都要）
14. 「紀錄」分頁：組別異動和提案紀錄要合成一條線，還是兩段？（建議先兩段）

## 要別人做的事

- **共用**：側欄三項、徽章改讀學生的待辦清單、Pixel Trail 元件、頭像元件、共用版本表加一個「不顯示表單版本」開關、深色模式顏色、效能目標。
- **訪客**：前台合作案詳情的組長「連結到我的組別」按鈕拿掉；首頁「我的工作」列的字改「交作業」；置頂公告測試的定位跟學生首頁對齊。
- **老師**：老師首頁連到 `/timeline`；之後補「全屆作業截止」查詢；同意書「還沒回覆」的字。
- **系辦**：「連結合作案」「改組別類型」對話框。
- **主腦**：裁定幾個沒人認領的檔案歸誰（組別查詢加 Email、幾個跨角色測試檔的學生段落）。
