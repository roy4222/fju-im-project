# 規格⑤ 白話版（給 Roy）

這份規格是 C 階段的「收尾包」：修一個走查抓到的驗證碼小毛病、把監測換成你要的樣子（Cloudflare 擋前面、壞消息送 Discord）、拆掉開發者後台、把舊票和技術債一次裁掉。沒有資料庫改動。18 張票，大約 60 小時工時，大部分可以跟①②③的波次並行。

## 一、會改什麼

1. **驗證碼頁不再「輸入了卻跳回去」**。你在第 2 步輸入驗證碼成功後，按上一頁不會再看到舊的驗證碼表單；如果開了兩個分頁、其中一個已經驗證完，另一個分頁再輸入會看到紅字「這個 Email 已經驗證，請到第 3 步。」和一個連結，而不是莫名其妙被丟回去。「我的帳號」頁的驗證 Email 也一樣。走查留下的三條紅色測試會變綠。
2. **你 10/18 的 hotfix（待審的人看得到首頁封面）補上測試**，以後有人改回去測試會紅。
3. **大檔案交給 Cloudflare 快取**。公開的 PDF、海報、封面會被 Cloudflare 存 5 分鐘，第二個人下載就不經過 VM。下架之後最多 5 分鐘內還拿得到舊檔，跟現在首頁圖片一樣。私有檔一律不存。
4. **Cloudflare 擋在 VM 前面**。程式這邊只改 Caddy 設定（讓它認得 Cloudflare 傳來的真實 IP，否則登入限速會把全校一起鎖）和一支「只讓 Cloudflare 連進 VM」的腳本（Review 抓到原本用 ufw 擋不住 Docker 開的埠，已改成 Docker 認得的擋法，而且重開機不會掉），其餘是你在 Cloudflare 後台點的設定，寫成一份步驟清單放在 `ops/README.md`。
5. **監測換成兩條**：GitHub 每 10 分鐘打網站，掛了就丟 Discord；Healthchecks.io 看三件定時工作（每日備份、自動部署、worker）有沒有準時「回報」，沒回報就丟 Discord。磁碟超過 80% 也會從每日備份那條報出來。
6. **拆掉開發者後台**（fju-status）：repo、CI、VM、教學影片第 6 章、術語表全部清掉，#570 一起關。開站清單的 G2／G4 改成「看 Vault 驗收報告」和「Healthchecks.io 備份綠燈」。
7. **舊票**：#410／#412／#416（教學影片工具）合成一張在重錄前做；#411 的兩件事（資料庫鎖的順序、本機工具不准自己刪別人的鎖）寫進工程文件與教學工具 README；#182（封存後唯讀）補一組測試（含封存與送出同時發生的兩種順序、封存後重送舊請求、解封後逾期）；#334 最後一項「整體架構與資安審查」做成一張收尾票，產出一份審查報告。#323／#324／#325 查過沒有殘項，不開票。
8. **技術債**：4 條偶爾紅的測試修穩、`.gitignore` 補一行、效能量測超標的封面查詢修掉、字數計算統一（emoji 算 1 個字）。其他幾項不做，理由在設計方案 §9、§12。
9. **B 版測試的殘項**：驗收腳本找不到「屆別」標題的問題跟著新設定頁修；示範資料的 11 個問題（沒密碼、沒預設屆別、重名、檢查碼一樣、王小明……）做成一張獨立票，排在③的示範資料票之後。測試站上已經有的舊示範資料要先清掉再重建（用既有的 `--remove`，它只刪示範屆別、不動其他屆別的設定：原本預設是真實屆別的話，清完仍是它），步驟會寫在票裡；重建後示範屆別會變成系辦首頁的預設屆別，開放註冊的屆別不會被動到。
