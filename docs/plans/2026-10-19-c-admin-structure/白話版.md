# C 階段規格② 白話版（給 Roy）

這份規格管三件事：**後台每個項目裡面怎麼分頁**、**帳號與設定這兩頁**、**前台怎麼讓系辦直接改**。左邊側欄照你 18:30 說的完全不動。

## 一、改之前 vs 改之後

| 你會碰到的地方 | 現在 | 改完 |
|---|---|---|
| 點側欄「設定」 | 先到一頁四張卡，再點一次才進去 | 直接進「屆別」，上面三個分頁：屆別｜專題時程｜操作紀錄。沒有「首頁設定」、沒有「模擬時鐘」 |

| 「公告與作業」 | 三個分頁，所有類別混在一頁 | 六個分頁：公告｜作業｜資源下載｜專題規則｜成果展示｜檔案。同意書在「作業」裡、榮譽榜在「成果展示」裡（內容是規格①做） |
| 「分組」 | 分組總覽｜合作案 | 全部組別｜未分組學生｜產學合作（內容是規格③做） |
| 「成績」 | 成績管理｜結算｜同意書，評分規則藏在小字 | 成績表｜評分規則｜評分老師｜結算 |

## 二、這份不做的

- 公告、作業、成績那些分頁**裡面**長什麼樣、表單怎麼填（規格①）。
- 分組、名片卡、頭像、產學合作、專題時程的內容與前台時程頁（規格③）。
- 外觀、動畫、深色、手機版（④）；OTP、Cloudflare、Discord（⑤）。
- 學生改成老師、老師改成學生（建議不做：停用再新增一個）。

## 三、要你拍板的（`待問.md` 共 12 題，每題都有建議答案）

最重要的四題：

1. 三張卡中間那張「我的入口／使用平台」是看登入狀態變的，**不開放編輯**，可以嗎？
2. 頁尾、三張卡、隱私權、大圖標語這幾個「站內文字」的表單，由規格②自己做（規格①只做公告那類）？
3. 如果公告的編輯視窗（有富文字編輯器）讓系辦的前台首頁超過 250 KB 上限，公告類的「編輯」改成跳到後台編輯器、改完跳回來，可以嗎？
4. 新增學生時是直接開通（不用他再申請），還是只寄註冊信讓他自己走申請？建議直接開通。

## 四、什麼時候能看到

拆成 20 張票、5 波；前兩波（路由、分頁外殼、帳號拆分、前台登入後同訪客）做完就能在 `stage-c` 看到整個骨架，後三波補帳號功能與前台編輯。
