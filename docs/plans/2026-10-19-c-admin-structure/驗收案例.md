# C 階段規格② — 驗收案例

- 每條四欄：前置狀態／操作／預期可觀察結果／在目前版本（`69116fc`）上會怎麼失敗。兩位專家看同一條要得到同樣結論，所以「預期」只寫看得到、量得到的東西（文字、URL、HTTP 狀態、資料列、位元組）。
- 編號 AC-C2-01～AC-C2-44；最後一條（AC-C2-44）是端到端。對應票見 `拆票.md` 每票第四欄。
- 示範帳號用 seed-demo 的（系辦 `office-admin@demo.invalid`、學生 SX1、老師 T1）；資料庫驗證用 verify 隔離庫的 `psql`，證據存 `/tmp/<票>-sql-<n>.json`（B 階段規矩）。
