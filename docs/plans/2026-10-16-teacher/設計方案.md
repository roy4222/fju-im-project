## 3. 共同規則（整個老師後台）

- **文字**：全站叫「作業」「作業區」「交作業」（Q83）；「認領」→「擔任指導老師」（Q52）；「暫存」→「儲存草稿」；「正式送出」保留；第 N 次送出；「我的評分」頁名改「評分」；「各組繳交」留作分頁名（決定頁原文）。
- **請洽系辦（Q81）**：所有說明段、提示句、頁面描述裡的「請洽系辦」「要改請系辦退回」「交系辦處理」拿掉；只有**被擋下的錯誤訊息**（後端 `err()` 回的 message、`blockReason`）可以留「請聯絡系辦」。逐行清單見 §8。
- **權限原則 Q47**：不能用的入口不顯示。老師沒有評分指派 → 首頁不出現「繼續評分」與待評卡；沒有指導組 → 作業區顯示空狀態而不是空表。
- **通知只走鈴鐺（§1 共用）**：`/dashboard/teacher/inbox` 頁保留（鈴鐺連過去、`pg-inbox.ts` 的連結不變），側欄不再列「通知」。
- **卡片不是表格**：各組繳交、我的組別、評分總覽都用卡片格；DataTable 只留在「全部組別」（分組總覽內搜尋篩選用）。
- **伺服器元件優先**：每頁一個 server component 讀一次資料；client component 只留需要互動的：評分表、分頁切換（可用 `<Link>` 加 `?tab=`，不必 client）、擔任指導老師對話框、合作案表單、作業篩選。
