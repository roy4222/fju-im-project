# C 階段規格③ 白話版（給 Roy）

這份只講「現在長什麼樣 → 改完長什麼樣」。依據是 10/18 的走查定案表；要問你的事另外列在《待問》，共 10 題。

## 一、頭像：後台有人名的地方都有頭像

| 現在 | 改完 |
|---|---|
| 系辦的組別表、老師的組別表、學生找組員名單，全是文字名字；有些地方放一個姓氏字的圓圈 | 後台凡是出現人名，旁邊就有頭像（含操作紀錄的操作者）；有上傳照片就是照片，沒有就是那一百張預設圖裡固定的一張。沒有姓氏字圓圈了。照片誰看得到不變：登入的人都看得到，訪客看不到 |
| 上傳照片後系統自己決定裁哪一塊 | 選完照片先跳一個圓形框：可以拖動照片、放大縮小，看好了再按「儲存」。存下來的還是正方形小圖，舊照片和預設圖都不受影響 |

技術上：頭像的兩個欄位跟名字是同一句查詢帶出來的，不會因為人多就多查幾次；裁切是自己寫的，不加套件，體積很小。

## 二、名片卡：學生在「我的帳號」寫自己的名片，找隊員時看卡片

| 現在 | 改完 |
|---|---|

| 沒有地方寫自介 | 「我的帳號」多一張「我的名片」卡（只有學生有），按「編輯我的名片」改自介、技能、Email、要不要公開找隊員 |
| 「公開找組員」 | 改叫「公開找隊員」。開著的人才會出現在名單、Email 才給同屆看；電話永遠不公開（跟現在一樣） |
| — | 按「邀請加入」會把對方的學號填進「建立組別」表單；可以連按幾張卡一起填。已經送出建立的人按不了，旁邊寫原因 |

## 三、學生「組別」頁：兩個分頁，沒分組就直接看到「建立組別」

| 現在 | 改完 |
|---|---|
| 三個分頁「我的組｜找隊員｜紀錄」；沒分組預設跳到「找隊員」 | 兩個分頁「我的組｜找隊員」；沒分組時「我的組」就是「建立組別」表單；「紀錄」併到「我的組」最下面 |
| 「發起提案」「提案人」「組隊中」「作廢」 | 「建立組別」「發起人」「建立中（等全員確認）」「終止建立」。流程不變：輸入學號 → 對方確認 → 全員確認成立 |
| 輸入學號看不到是誰 | 輸完學號馬上顯示那位同學的頭像與姓名；學號錯或對方已有組別會說 |
| 建立產學組不問合作案 | 選「產學合作」時要選一個合作案（只列已發布的）；成組後由那個合作案的負責老師確認要不要帶 |

## 四、系辦「分組」：三個分頁、卡片、沒有組隊中與最近終止

| 現在 | 改完 |
|---|---|
| 「分組總覽｜合作案」兩個分頁，總覽一頁塞了未分組、全部組別、已解散、組隊中、最近終止五個區塊 | 「全部組別｜未分組學生｜產學合作」三個分頁（分頁外殼是規格②做的）；組隊中、最近終止、已解散三個區塊都拿掉 |
| 全部組別是一張表 | 每組一張卡：代碼、類型、合作案、指導老師、組員頭像一排（組長戴冠冕，點名字跳到帳號頁）、人數。卡底三顆「＋加人」「移除」「進入小組」，右上「更多」裡有編輯、指派老師、連結合作案、刪除 |
| 「詳情」是彈窗 | 「進入小組」是一整頁：組員表、指導老師、合作案、異動紀錄，想做的事都在這頁做 |
| 「解散」且理由必填 | 「刪除」且理由可不填（確認兩次不變）。已有繳交的組不能刪，按鈕反灰寫原因 |
| 加人、重派老師、換組長、換合作案、改類型都要填理由 | 全部理由可不填 |
| 要先去「組隊中」作廢，才能把那位同學加到別組 | 在「未分組學生」裡，那位同學的列就寫「建立中（發起人 X）」，旁邊直接「終止建立」 |
| 只有匯出 | 匯出照舊，加「匯入」：上傳「學號, 組別代碼, 類型」的 CSV，先預覽每一列會發生什麼（建新組／加人／跳過的原因），再執行 |
| 合作案的刪除在「危險操作」區，發布中的要先下架才能按 | 每一列都有「刪除」；不能刪的直接反灰寫「先下架」或「先解除連結」。沒有危險操作區 |

用詞：「加入某組」→「＋加人」、「移出」→「移除」、「詳情」→「進入小組」。

## 六、專題時程：系辦用甘特圖排，學生老師看同一張（唯讀）

| 現在 | 改完 |
|---|---|
| 系辦「設定›專題時程」是蛇形時間軸＋「編輯階段與日期」彈窗；活動分「已排定」「已取消」「危險操作」三區 | 一張甘特圖：上面四段階段色塊，下面每段一列放活動橫條，作業截止是小菱形，今天一條橘線。互動像 Google 日曆：點橫條編輯、點空白新增、拖橫條改日期、拉兩端改起訖、右鍵「編輯／刪除」、鍵盤方向鍵也能改、可切週／月。下面一張「活動清單」每列「編輯」「刪除」 |
| 活動只能一天 | 活動可以跨好幾天（有開始日、結束日）。有時間的活動跨日時要填結束時間（單日才可以不填） |
| 排定中的活動要先「取消」才能刪 | 每列直接「刪除」，確認一次就刪。沒有「取消」了（以前取消過的舊活動還看得到，只剩刪除） |
| 改階段日期在彈窗裡填 | 直接拖階段分界或年度結束日；放開前會跳一個確認框，告訴你哪兩段變了、會提醒幾個有作業的組。「階段日期」「還原」兩顆鈕拿掉；名稱與說明點色塊就能改 |
| 改階段日期不通知任何人 | 改了日期範圍，就通知「那一段有整組作業」的組（只通知他們、一組一則）。沒作業的組、老師、沒分組的學生不吵 |
| 學生、老師的 `/timeline` 是整月行事曆 | 電腦版是同一張甘特（唯讀，不能拖）；手機是依月份排的清單 |
| 前台導覽列沒有時程入口 | 登入後的導覽列多「專題時程」（在「專題規則」後面；訪客看不到，因為這頁本來就要登入）。三個角色首頁橫幅都有「看完整時程」連過去 |
| 手機 | 系辦在手機上不能拖，退回「點一下編輯」；學生手機看清單 |

技術上：甘特自己寫、不用套件；位置用瀏覽器端設定、不會踩到 CSP；系辦時程頁現在 229.7 KB，預估加 5～6 KB、上限 250 不動；前台 `/timeline` 也會量。

## 七、不做的事（這次刻意不碰）

- 不做組別名稱／題目（模擬圖上的「智慧校園導覽系統」是假字）。
- 不改分組規則：一人一組、全員確認、人數上限、分組期截止都不動。
- 不做手機拖拉、不做活動提醒、不做多屆並排、不做匯出圖片。
- 不動側欄（你 18:30 說的）；分頁外殼、路由是規格②。

## 八、順序

17 張票、6 波。第 0 波是資料結構、頭像共用件、甘特元件、裁切，彼此不相干可以同時做；之後分組與時程兩條線各自往下，最後一張是系辦「全部組別」卡片（它要等未分組、匯入、分頁外殼都好）。導覽列、我的帳號掛名片這兩張要等規格②的外殼合進來。
