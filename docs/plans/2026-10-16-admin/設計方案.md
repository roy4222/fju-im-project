## 1. 設計原則（定案頁 §1，Review 時逐條檢查）

1. **不寫廢話**：說明文字只在使用者被擋住時說原因。每一頁的 `description`、Panel 的 `hint`、表格上下的灰字，預設拿掉；留下的每一句都要能回答「少了它使用者會做錯什麼」。
2. **依權限只顯示能用的入口**（Q47）：系辦看不到的功能不出現。這份規格裡所有新入口都在 `requireRole('admin')` 之後才渲染。
3. **少表格、多卡片與圖表；資訊不重複**（Q69、Q81、Q89）：表格只留帳號、組別、成績表、檔案。
4. **用詞簡單、現代**：套 `2026-10-12 用詞圈選第 2 輪.md` 最右欄（#30 改照 Q83 全站叫「作業」）。
5. **配色照原本、版面採原型第 3 輪**（Q87）：大粗標題、區塊標題後細線、彩色邊框待辦卡、分頁在標題下。深色模式由共用規格負責。
6. **效能**：每頁一次聚合讀取為目標；側欄徽章共用頁面資料；不准 N+1；每頁寫明 Server Component 與 client 元件清單（§8）。
