## Q-A1 編輯器頁的 JS 體積上限可以提高到多少？

- 背景：Q184 選 Tiptap（MIT、輸出 HTML、能對齊現有白名單）。編輯器會動態載入，理論上不算進 First Load JS；但若量測仍超過目前上限 250（gz KB，現值 241.7），Q106 的「現值 +10%」規則只允許到 265。
- 建議：先照 +10% 把 editor 路由上限調到 265；若 Tiptap 載入後實測超過 265，**允許編輯器頁（只有系辦用）上限到 300**，其他路由不動。
- 實作票 A-10 的停下條件跟這題一致：沒回覆就照建議，超過 265 直接調到 300、不停下；**超過 300 才停下回報**。

## Q-A2 結算成績時要不要通知老師？

- 背景：系辦對某階段按「結算」後，老師那個階段變唯讀、看到「已結算」標示。
- 建議：**不通知**。結算是系辦的帳務動作，老師進評分頁就看得到；少一種通知少一分噪音。要通知的話只多一行 `EVENT_CATALOG`，之後可加。

## Q-A3 已經正式繳交的學生，還能被設成「免繳」嗎？

- 背景：設免繳會把人從完成率分母拿掉；若學生已繳，繳交內容保留、名單標免繳。
- 建議：**可以**。免繳是系辦與學生線下談好的結果，不該被「已繳過」擋住；畫面會提示「這位已經繳交，設免繳後繳交內容保留」。

## Q-A4 清掉網站這邊的磁碟量測後，「磁碟 80%」演練只留在 status 那邊，可以嗎？

- 背景：G8 要刪網站裡的儲存量程式（首頁磁貼早已移除，status 收集器自己量磁碟）。網站的故障演練測試裡有一條「演練 4：磁碟 80%」是靠被刪的程式跑的。
- 建議：**可以**，刪掉演練 4，磁碟告警的驗證改在 status 的告警規則測試看。
