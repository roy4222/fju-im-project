2. **處理時點（▶R-4）：上傳完成、轉成 `stored` 之前。** 既有 `FsFileStorage.upload()`（`file-storage.ts:156-270`）把通過內容檢查的原始位元組直接標 `stored`。SH-9 在 `FileStorage` 的建構選項加 `transforms?: Partial<Record<FilePurpose, (input: Buffer) => Promise<{ bytes: Buffer; mime: string }>>>`（`composition/ops.ts` 的 `getFileStorage()` 登記 `avatar: avatarImageTransform`），`upload()` 在內容檢查通過後、寫 `status='stored'` 前：有 transform 就把暫存檔整個讀進記憶體（≤ 2 MiB）→ 呼叫 → 用輸出覆寫暫存檔 → **以輸出重算 `size_bytes`、`checksum`、`mime_detected = 'image/webp'`** → 再搬到正式位置標 `stored`。transform 丟錯 → 回 `err('FILE_TYPE_REJECTED', '這張圖片無法處理，請換一張。')`，刪暫存檔，列維持 `uploading`（24 小時後既有 GC 收走，`file-storage.ts:495`）；**失敗的檔永遠不會成為可下載頭像**。
