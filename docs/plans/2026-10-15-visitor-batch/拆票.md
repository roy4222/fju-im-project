## 每張票的完成條件

- `pnpm lint && pnpm typecheck && pnpm vitest run` 綠；自己票的 integration test 在真 PostgreSQL 上綠；自己票列的 e2e 在 `build+start` 上綠。
- 「會受影響的既有測試」欄列的測試全部跑過，PR 說明寫「跑了哪些、結果」；改了任何既有測試要在 PR 說明逐行列出並引用衝突表編號（C1～C14）。
- PR 說明附對應 AC 的驗證紀錄（curl 輸出或截圖）；V4 另附 AC-V22、V24 兩條私有檔回歸的 curl 輸出，以及 AC-V19 連打 304 後 fd 數不增的證據。
- 不開新的「待決」：遇到規格沒寫的，回報架構師，不自己決定。
